# उपयोग (कमांड-लाइन विकल्प)

यह दस्तावेज़ uag एंट्री पॉइंट्स के लिए उपलब्ध कमांड-लाइन विकल्पों का वर्णन करता है।

______________________________________________________________________

## एंट्री पॉइंट्स

| कमांड | पाइथन मॉड्यूल | इंटरफ़ेस |
|---|---|---|
| `uag` | `python -m uagent` | CLI (stdin लूप) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | वेब सर्वर (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | A2A HTTP सर्वर |

## CLI स्टार्टअप विकल्प (`uag`)

### `--workdir` / `-C <path>`

कार्य निर्देशिका। यदि सेट नहीं किया गया है, तो यह `UAGENT_WORKDIR` एनवी वेरिएबल पर वापस चला जाता है, फिर वर्तमान डायरेक्टरी पर।
यदि डायरेक्टरी मौजूद नहीं है तो उसे बनाया जाता है।

### `--tool-genre-mask <int>`

टूल शैली बिटमास्क। जब प्रदान किया जाता है, तो इंटरैक्टिव शैली चयन प्रॉम्प्ट को छोड़ दिया जाता है।

| बिट | शैली | विवरण |
|-----|-------|-------------|
| 1 | basic | आवश्यक फ़ाइल/चैट उपकरण |
| 2 | comm | संचार उपकरण (ब्लूस्काई, टीम्स) |
| 4 | office | ऑफिस सुइट उपकरण (एक्सेल, पीडीएफ, पीपीटीएक्स) |
| 8 | devel | विकास उपकरण (गिट, लिंट, कंपाइल) |
| 16 | iot | IoT डिवाइस टूल्स (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | कमांड निष्पादन टूल्स |
| 64 | external | बाहरी प्लगइन टूल्स |
| 128 | मीडिया | छवि/ऑडियो निर्माण और विश्लेषण |
| 256 | फ़ाइल | फ़ाइल-प्रबंधन उपकरण |
| 512 | इंडेक्स | स्रोत/इंडेक्स नेविगेशन उपकरण |
| 1024 | डेवल | डेवलपर और रिपॉजिटरी उपकरण |
| 2048 | वेब | वेब और ब्राउज़र उपकरण |
| 4096 | यूटिलिटी | यूटिलिटी और सहायता उपकरण |
| 8191 | सभी | सभी उपकरण |

उदाहरण:

```
uag --tool-genre-mask 1 # केवल बुनियादी
uag --tool-genre-mask 9 # बुनियादी + डेवल (1 + 8)
uag --tool-genre-mask 8191    # सभी टूल्स
```

### `--use-tool` / `--no-use-tool`

LLM को टूल परिभाषाएँ भेजना सक्षम या अक्षम करें। `UAGENT_USE_TOOL` वातावरण चर को ओवरराइड करता है।

- `--use-tool` टूल भेजने को अनिवार्य रूप से चालू करता है।
- `--no-use-tool` टूल भेजने को अनिवार्य रूप से बंद करता है।

जब अक्षम किया जाता है, तो LLM को कोई टूल परिभाषाएँ प्राप्त नहीं होती हैं और यह किसी भी टूल को कॉल नहीं कर सकता है।

### `--computer-use` / `--no-computer-use`

कंप्यूटर उपयोग को सक्षम या अक्षम करें। `UAGENT_COMPUTER_USE` पर्यावरण चर को ओवरराइड करता है।

### `--inject-message` / `-M <message>`

स्टार्टअप पर LLM में एक संदेश इंजेक्ट करता है और पूर्ण होने के बाद बाहर निकलता है। यह `--non-interactive` को इंगित करता है।

### `--embedded`

प्रतिबंधित या पुनरुत्पादन-संवेदनशील तैनाती के लिए एम्बेडेड मोड।

- सत्र स्टोर को अक्षम करता है।
- जब तक स्पष्ट रूप से सक्षम न किया जाए, तब तक टूल-प्रबंधन टूल्स (`tool_catalog`, `tool_load`, `unload_tool`) को छिपाता है।
- `--tool-genre-mask` को अनदेखा करता है; स्पष्ट टूल लोडिंग के लिए `--enable-tool` का उपयोग करें।

### `--enable-tool <name>`

स्टार्टअप पर एक टूल को स्पष्ट रूप से लोड करें। इस विकल्प को दोहराया जा सकता है, और अल्पविराम से अलग किए गए नाम भी स्वीकार किए जाते हैं।

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

निर्दिष्ट क्रम को संरक्षित किया जाता है और LLM को प्रस्तुत किए गए टूल क्रम में यह परिलक्षित होता है। स्पष्ट रूप से सक्षम किए गए टूल स्वचालित अनलोडिंग से सुरक्षित रहते हैं।

### `--plugin-dir <path>`

निर्दिष्ट निर्देशिका से प्लगइन्स लोड करें। इस विकल्प को दोहराया जा सकता है।

## केवल CLI विकल्प

### `--inject-message-auto <goal-options>`

एक गैर-इंटरैक्टिव इंजेक्टेड गोल से ऑटो-पायलट शुरू करें। यह मान `:auto` के समान विकल्पों का उपयोग करता है; जब इसमें विकल्प हों तो पूरे मान को उद्धृत करें।

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --infinite"
```

सामान्य मोड समीक्षक के निर्णय पथ का उपयोग करता है। एकल-LLM सेंटिनल मोड में शामिल होने के लिए `UAGENT_AUTO_SENTINEL=1` सेट करें। उस मोड में, टारगेट LLM को प्रत्येक प्रतिक्रिया को इनमें से ठीक एक के साथ समाप्त करना चाहिए:

- `<AUTO_CONTINUE>` — एक और राउंड चलाएँ
- `<AUTO_COMPLETE>` — सफलतापूर्वक समाप्त करें

अनुपस्थित या अमान्य मार्कर सुरक्षित रूप से ऑटो-पायलट को रोकते हैं। यह फिर भी लक्ष्य LLM को चलाता है; यह केवल अतिरिक्त समीक्षक LLM कॉल से बचता है।

### `--non-interactive`

गैर-इंटरैक्टिव मोड। stdin लूप शुरू नहीं करता। यदि किसी फ़ाइल पथ को पोजिशनल आर्गुमेंट के रूप में दिया जाता है, तो उसे प्रोसेस किया जाता है और प्रोग्राम तुरंत बाहर निकल जाता है।

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## वेब सर्वर विकल्प (`uagw`)

### `--host <पता>`

वेब सर्वर के लिए बाइंड पता (डिफ़ॉल्ट: `127.0.0.1`, `UAGENT_WEB_HOST` द्वारा ओवरराइड किया जा सकता है)।

डिफ़ॉल्ट रूप से, वेब सर्वर केवल लोकलहोस्ट (`127.0.0.1`) पर सुनता है। नेटवर्क पर अन्य मशीनों से इसे सुलभ बनाने के लिए, `--host 0.0.0.0` का उपयोग करें।

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

उपरोक्त वर्णित उसी बिटमास्क का उपयोग करके टूल शैलियों का चयन करें। निर्दिष्ट किए जाने पर, इंटरैक्टिव शैली प्रॉम्प्ट को छोड़ दिया जाता है।

### `--use-tool` / `--no-use-tool`

LLM को टूल परिभाषाएँ भेजना सक्षम या अक्षम करें। `UAGENT_USE` को ओवरराइड करता है।

### `--computer-use` / `--no-computer-use`

कंप्यूटर उपयोग को सक्षम या अक्षम करें। `UAGENT_COMPUTER_USE` को ओवरराइड करता है।

### `--no-frontend`

HTML टेम्प्लेट या स्थिर फ्रंटएंड फ़ाइलों के बिना केवल API चलाएँ।

### `--embedded`

सत्र स्टोर को अक्षम करें और टूल-प्रबंधन टूल्स (`tool_catalog`, `tool_load`, `unload_tool`) को छिपाएँ।

## A2A सर्वर विकल्प (`uaga`)

### `--host <पता>`

A2A HTTP सर्वर के लिए बाइंड पता (डिफ़ॉल्ट: `0.0.0.0`, `UAGENT_A2A_HOST` द्वारा ओवरराइड किया जा सकता है)।

### `--port <संख्या>`

A2A HTTP सर्वर के लिए पोर्ट नंबर (डिफ़ॉल्ट: `8765`, `UAGENT_A2A_PORT` द्वारा ओवरराइड किया जा सकता है)।

### `--reload`

कोड परिवर्तनों पर हॉट रीलोड सक्षम करें (डिफ़ॉल्ट: बंद, `UAGENT_A2A_RELOAD` द्वारा ओवरराइड किया जा सकता है)।

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

उपरोक्त वर्णित बिटमास्क का उपयोग करके टूल शैलियों का चयन करें। जब निर्दिष्ट किया जाता है, तो इंटरैक्टिव शैली प्रॉम्प्ट को छोड़ दिया जाता है।

### `--use-tool` / `--no-use-tool`

LLM को टूल परिभाषाएँ भेजना सक्षम या अक्षम करें। `UAGENT_USE_TOOL` को ओवरराइड करता है।

### `--computer-use` / `--no-computer-use`

कंप्यूटर उपयोग को सक्षम या अक्षम करें। `UAGENT_COMPUTER_USE` को ओवरराइड करता है।

### `--embedded`

सत्र स्टोर को अक्षम करें और टूल-प्रबंधन टूल (`tool_catalog`, `tool_load`, `unload_tool`) को छिपाएँ।

## संबंधित वातावरण चर

| चर | विवरण |
|---|---|
| `UAGENT_PROVIDER` | LLM प्रदाता का नाम (शुरुआत में आवश्यक) |
| `UAGENT_*_API_KEY` | चयनित प्रदाता के लिए API कुंजी |
| `UAGENT_WORKDIR` | डिफ़ॉल्ट कार्य निर्देशिका |
| `UAGENT_WEB_HOST` | वेब सर्वर बाइंड पता (डिफ़ॉल्ट: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A सर्वर बाइंड पता (डिफ़ॉल्ट: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | A2A सर्वर पोर्ट (डिफ़ॉल्ट: `8765`) |
| `UAGENT_A2A_RELOAD` | डिफ़ॉल्ट रूप से A2A हॉट रीलोड सक्षम करें |
| `UAGENT_USE_TOOL` | `0`, `false`, `no`, या `off` पर सेट होने पर टूल्स अक्षम करें |
| `UAGENT_COMPUTER_USE` | डिफ़ॉल्ट रूप से कंप्यूटर उपयोग सक्षम या अक्षम करें |
| `UAGENT_SESSION_STORE` | सत्र स्टोर को सक्षम या अक्षम करें; एम्बेडेड मोड `0` को लागू करता है |
| `UAGENT_PLUGIN_DIRS` | अतिरिक्त प्लगइन खोज निर्देशिकाएँ |
| `UAGENT_AUTO_SENTINEL` | जब `1` पर सेट हो तो एकल-LLM ऑटो-पायलट सेंटिनल मोड में शामिल हों |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | अधिकतम लगातार नए टूल कॉल (डिफ़ॉल्ट: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | प्रति उपयोगकर्ता ऑपरेशन में अधिकतम LLM/टूल राउंड (डिफ़ॉल्ट: `200`) |
| `UAGENT_SHRINK_CNT` | संदेशों में वैकल्पिक ऑटो-श्रिंक थ्रेशोल्ड (`0`/अनसेट = अक्षम) |
| `UAGENT_SHRINK_KEEP_LAST` | श्रिंक के बाद रखने के लिए संदेश (डिफ़ॉल्ट: `20`) |
| `UAGENT_LANG` | इंटरफ़ेस भाषा (`ja`, `en`, आदि) |

पर्यावरण चरों की पूरी सूची के लिए, [ENVIRONMENT.md](ENVIRONMENT.md) देखें।

## उदाहरण

### OpenAI के साथ न्यूनतम शुरुआत

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### केवल बुनियादी टूल्स के साथ लोकल ओल्लामा

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### सभी इंटरफेस पर वेब सर्वर

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

या

```
uagw --host 0.0.0.0
```

### A2A कस्टम पोर्ट के साथ लोकलहोस्ट पर सर्वर

```
uaga --host 127.0.0.1 --port 8080
```

### छोटे मॉडल के लिए टूल्स अक्षम करें

```
uag --no-use-tool --tool-genre-mask 1
```

### गैर-इंटरैक्टिव फ़ाइल प्रोसेसिंग

```
uag --non-interactive README.md
```
