## Яагаад uag гэж?

**Үйлчилгээ үзүүлэгчийн түгжрэлээс сал.** Ихэнх хиймэл оюун ухааны туслахууд таныг тодорхой үйлчилгээ үзүүлэгч эсвэл үүлэн үйлчилгээтэй холбодог. uag өөр байна.

- Таны машин дээр **Дотоодоор ажилладаг**. Таны өгөгдөл тантай хамт үлдэнэ (таны хийсэн API дуудлагаас бусад).
- **Үйлчилгээ үзүүлэгчийн эрх чөлөө**: OpenAI, Claude, Gemini, DeepSeek, Ollama, Azure, Bedrock, Novita, HuggingFace... 24 үйлчилгээ үзүүлэгч, бүгд нэг интерфейсээс хандах боломжтой. Орчны хувьсагчдыг дахин тохируулах замаар тэдгээрийн хооронд солигоорой — дахин суулгахгүй, шилжүүлэхгүй.
- **222 хэрэгсэл**: Файл оруулах/гаралт, вэб хайлт, зураг үүсгэх, Gmail, BLE төхөөрөмж скан хийх, MCP серверийг нэгтгэх — **130 нь параллель-аюулгүй гэж статикаар тэмдэглэгдсэн** (пөөрлөөр дамжуулан 8 хүртэл удаа гүйцэтгэх боломжтой, нэгэн зэрэг тохируулах боломжтой. `UAGENT_PARALLEL_WORKERS`). LLM нь олон хэрэгслийн дуудлагыг нэгэн зэрэг хийх үед uag нь тэдгээрийг автоматаар зэрэгцүүлдэг.
- **3 UI + A2A**: CLI, GUI, Web болон Agent-to-Agent протокол. Ижил хөдөлгүүр, дурын интерфейс.
- **IoT-д бэлэн**: SwitchBot, ECHONET Lite, Matter, UPnP — AI-аар дамжуулан гэрийн төхөөрөмжүүдээ удирдаарай.
- **Агентны ур чадвар**: Зах зээлээс нийгэмд бий болгосон ур чадварыг суулгаарай. uag-ийг эцэс төгсгөлгүй сунгаарай.

uag бол **таны AI туслах болно**. Үйлчилгээ үзүүлэгчтэй холбоогүй, интерфейстэй холбоогүй, платформтой холбоогүй.

## Computer Use

Computer Use нь бүртгүүлсэн бөгөөд харагдахуйц Playwright хөтчийн ажиллах цаг
болон ширээний ажиллах хугацааг хоёуланг нь дэмждэг. Идэвхжүүлсэн үед ажиллах цаг хоёуланг нь үүсгэн бүртгэнэ;
сонгосон ажиллах цагийг `UAGENT_COMPUTER_ENVIRONMENT` удирддаг:

````bat
set UAGENT_COMPUTER_USE=1
UAGENT_COMPUTER_ENVIRONMENT=хөтчийг `top`-г сонгох

`Us`-г сонго. оронд нь ширээний ажиллах цаг. Runtime нөөцүүд нь `Ctrl-C` хэвийн гарц, процесс унтрах үед хамтдаа хаагдсан. Хөтөч дээр суурилсан CI эсвэл утааны туршилтын хувьд
`UAGENT_COMPUTER_HEADLESS=1`-г тохируулна уу.
Интеграцчлал, аюулгүй байдлын дэлгэрэнгүй мэдээллийг [docs/COMPUTER_USE_IMPLEMENTATION.md](docs/COMPUTER_USE_IMPLEMENTATION.md)

### ⚡ Зэрэгцээ хэрэглүүр гүйцэтгэх

LLM нэгэн зэрэг олон хэрэгсэл хүсэх үед uag **автоматаар зэрэгцээ болгодог**, `x_130 хэрэглүүрүүдийг `статтай байдлаар тэмдэглэнэ. `ThreadPoolExecutor`-аар нэгэн зэрэг гүйцэтгэх (анхдагчаар 8 хэлхээс; өөрчлөхийн тулд `UAGENT_PARALLEL_WORKERS`-г тохируулна уу).

**Жишээ**: "Скандинавын нийслэл дэх цаг агаарыг шалгах" → LLM гал түймэр `хайлтын_вэб`-д зэрэгцэн → бүх улс оронд хайлтын үр дүнг цуглуулсан × 5 багц.

Одоогийн тоо нь `TOOL_SPEC`-г (одоогоор 222, `src/uagent/tools_rust/` доторх зэвээр дэмжигдсэн 2 хэрэгслийг багтаасан) тодорхойлсон хэрэгслийн модулиудад үндэслэсэн болно. `http_request` нь аргад мэдрэмтгий аюулгүй байдлыг ашигладаг: `GET`/`HEAD`/`OPTIONS` дуудлагууд зэрэгцэн ажиллаж болох ба бичих аргууд нь цуваа хэвээр үлдэнэ.

Зөвхөн уншихад зориулагдсан хэрэгслүүд (файл хайх, хэш тооцоо, лавлах жагсаалт, орчуулга, DB асуулга гэх мэт) P System

#⏧#lug-д маш хүчтэй зэрэгцээ хийгдсэн байдаг. (Claude Код нийцтэй)

uagent нь **Claude Код нийцтэй залгаасын системийг** хэрэгжүүлдэг. Залгааснууд нь ур чадвар, агентууд, MCP серверүүд, дэгээнүүд болон бусад зүйлийг `.claude-plugin/plugin.json` манифест бүхий бие даасан лавлахуудад нэгтгэдэг.

**Дэмждэг бүрэлдэхүүн хэсгүүд**: Ур чадвар, Дэд агентууд, MCP (серверүүд, Hook2-н командын үйл явдлууд, Output-ийн үйл явдлууд), userConfig, Dependencies, Channels, Marketplaces

**CLI командууд**:

```

: залгаасуудын жагсаалт # Суулгасан залгаасуудын жагсаалт
: залгаас суулгах <source> [--scope] # Суулгах (dir/zip/git/http)
:plugin суулгах <name>market #pplace:<name>market-аас суулгах # Устгах
: залгаасыг идэвхжүүлэх/идэвхгүй болгох \<нэр> # Тоглуулах
: залгаас зах зээл нэмэх/хасах/жагсаалт # Зах зээлийг удирдах
: залгаас эхлүүлэх \<нэр> # Scaffold шинэ залгаас

````

Харна уу Бүрэн баримтжуулалтыг [DEVELOP_PLUGIN.md](src/uagent/docs/DEVELOP_PLUGIN.md). `:load <index>` бүхий сессүүд** — орхисон газраасаа үргэлжлүүлнэ үү.
