## Яагаад uag гэж?

\*\* Борлуулагчийн түгжээг таслан зогсоо.\*\* Ихэнх хиймэл оюун ухааны туслахууд таныг тодорхой үйлчилгээ үзүүлэгч эсвэл үүлэн үйлчилгээтэй холбодог. uag өөр.

- **Таны машин дээр орон нутагт ажилладаг**. Таны өгөгдөл тантай хамт үлдэнэ (таны API дуудлагаас бусад).
- **Үйлчилгээ үзүүлэгчийн эрх чөлөө**: OpenAI, Claude, Gemini, DeepSeek, Ollama, Azure, Bedrock, HuggingFace... 21+ үйлчилгээ үзүүлэгч, бүгд нэг интерфейсээс хандах боломжтой. Орчны хувьсагчдыг дахин тохируулах замаар тэдгээрийн хооронд солигдох - дахин суулгахгүй, шилжихгүй.
- **229 хэрэгсэл**: Файл оруулах/гаралт, вэб хайлт, зураг үүсгэх, Gmail, BLE төхөөрөмж скан хийх, MCP серверийг нэгтгэх — **130 нь зэрэгцээ аюулгүй** (8 хүртэлх нь урсгалын сангаар нэгэн зэрэг ажиллах, `UAGENT_PARALLEL_WORKERS`-ээр тохируулах боломжтой). LLM нь хэд хэдэн хэрэгслийн дуудлагыг нэгэн зэрэг хийх үед uag автоматаар тэдгээрийг параллель болгодог.
- **3 UI + A2A**: CLI, GUI, Вэб, Агентаас Агент руу протокол. Ижил хөдөлгүүр, ямар ч интерфейс.
- **Агентны ур чадвар**: Олон нийтэд бий болгосон ур чадварыг зах зээлээс суулгаарай. Uag-г эцэс төгсгөлгүй сунга.

uag бол **таны нөхцлийн дагуу таны хиймэл оюун ухааны туслах болно**. Үйлчилгээ үзүүлэгчтэй холбоогүй, интерфейстэй холбоогүй, платформтой холбоогүй.

### ⚡ Зэрэгцээ багажийн гүйцэтгэл

LLM нь нэгэн зэрэг олон хэрэгслийг хүсэх үед uag нь **автоматаар зэрэгцээ болгодог**.
130 хэрэгслийг `x_parallel_safe` гэж тэмдэглэсэн бөгөөд `ThreadPoolExecutor`-аар нэгэн зэрэг гүйцэтгэнэ (анхдагчаар 8 урсгал; өөрчлөхийн тулд `UAGENT_PARALLEL_WORKERS`-г тохируулна уу).

**Жишээ**: "Скандинавын нийслэлүүдийн цаг агаарыг шалгах" гэж асуу → LLM `search_web` × 5 улсыг ажиллуулж байна → бүх 5 хайлт зэрэгцэн явагдана → үр дүнг нэг багцад цуглуулна.

Зөвхөн унших боломжтой хэрэгслүүд (файл хайлт, хэш тооцоо, лавлах жагсаалт, орчуулга, DB асуулга гэх мэт) нь маш хүчтэй зэрэгцээ хийгдсэн байдаг.

### 🧩 Plugin систем (Claude Code нийцтэй)

uagent нь **Claude Code-тэй нийцтэй залгаасын системийг** хэрэгжүүлдэг. Залгаасууд нь ур чадвар, агентууд, MCP серверүүд, дэгээнүүд болон бусад зүйлийг `.claude-plugin/plugin.json` манифест бүхий бие даасан лавлахуудад нэгтгэдэг.

**Дэмжигдсэн бүрэлдэхүүн хэсгүүд**: Ур чадвар, дэд агентууд, MCP серверүүд, дэгээнүүд (12 амьдралын мөчлөгийн үйл явдал), Slash командууд, гаралтын загварууд, userConfig, хамаарал, сувгууд, зах зээлүүд

**CLI commands**:

```
:plugin list                         # Суулгасан залгаасуудыг жагсаах
:plugin install <source> [--scope]
:plugin install <name>@<marketplace>  # Зах зээлээс суулгах
:plugin remove <name>                # Устгах
:plugin enable/disable <name>        # Сэлгэх
:plugin marketplace add/remove/list  # Зах зээлүүдийг удирдах
:plugin init <name>                  # Шинэ залгаасын бүтэц үүсгэх
```

Бүрэн баримт бичгийг [DEVELOP_PLUGIN.md](../src/uagent/docs/DEVELOP_PLUGIN.md)-ээс үзнэ үү.

### 🤖 Автомат нисгэгч (`:авто`)

uag нь **бие даасан зорилгыг LLM-ийн олон үе шатанд хэрэгжүүлэх боломжтой**. Давталттай сайжруулалт шаардлагатай олон шатлалт нарийн төвөгтэй ажлуудад төгс тохирно.

- **Энэ нь хэрхэн ажилладаг вэ**: Тойрог бүр үндсэн асуулгатай (Алхам А), дараа нь хянагчийн дүгнэлт (Б шат) "БҮРДҮҮЛЭХ үү, ҮРГЭЛЖЛҮҮЛЭХ үү?"
- **Ижил үйлчилгээ үзүүлэгч, ижил API**: Шүүгчийн дүгнэлт нь Responses API-ийн дэмжлэгийг багтаасан ижил кодын замыг үндсэн асуулга болгон ашигладаг.
- **Тусдаа шүүгч LLM** (заавал биш): Шүүгчид өөр үйлчилгээ үзүүлэгч/загвар ашиглахын тулд `UAGENT_AP_PROVIDER`-г тохируулна уу (жишээ нь шүүлтийн хувьд хямд загвар ашиглах).
- **Хүссэн үедээ гарах**: `x` товчийг дарж шууд, тэр дундаа ч гэсэн зогсооно. Эсвэл зорилгодоо хүрэхийг шүүмжлэгч өөрөө шийднэ.
- **Тохируулж болох**: `--max-rounds N` төсвийг хянах.

Бүрэн баримтыг [README_AUTO.md](README_AUTO.md)-с үзнэ үү.

### 🧩 Багц улсын менежер

uag нь урт хугацааны олон файлын даалгавруудын явцыг хянах боломжтой. LLM нь олон арван файлыг боловсруулах үед `batch_state` нь хүлээгдэж буй, дууссан, бүтэлгүйтсэн файлуудын жагсаалтыг дискэнд хадгалдаг. Хэрэв сесс дуусвал эсвэл тойрог дууссан бол дараагийн гүйлт зогссон газраасаа үргэлжилнэ - юу ч алдахгүй.

### 🛡 Давталт дахь хүн

`human_ask` нь LLM-д хор хөнөөлтэй үйлдлүүд (файлыг устгах, дарж бичих, бүрхүүлийн командууд) хийхээс өмнө түр зогсоож, баталгаажуулахыг хүсэх боломжийг олгодог. Та хяналтандаа байгаарай.

### 🛑 Тасалдах (c товчлуур / Зогсоох товч)

LLM хариу үүсгэхийг хүссэн үедээ зогсоож, зогсоох командыг LLM руу буцааж оруулна.

| Интерфэйс | Хэрхэн таслах вэ |
|---|---|
| **CLI** | LLM дамжуулалтын үед `c` товчийг дарна уу — одоогийн хариулт зогсох ба `"Stop"`-г хэрэглэгчийн мессеж болгон илгээснээр LLM зохих ёсоор хариу өгнө |
| **ВЭБ UI** | Улаан **■ Зогсоох** товчийг дарна уу (LLM боловсруулах явцад автоматаар гарч ирнэ) |
| **Ширээний GUI** | Улаан **■** товчийг дарна уу (LLM боловсруулах явцад автоматаар гарч ирнэ) |

Тасалдал нь "шууд тарилга" хэлбэрээр ажилладаг: энэ нь зүгээр л цуцлахын оронд "Зогс"-ыг LLM-д хэрэглэгчийн мессеж болгон буцааж өгч, тасалдлыг эелдэг байдлаар дүгнэх эсвэл хүлээн зөвшөөрөх боломжийг олгодог.

Автомат нисгэгчийн горимоос гарахын тулд `x` товчийг дарна уу ([README_AUTO.md](README_AUTO.md) хэсгийг үзнэ үү).

### 🕵️ Хөтөч автоматжуулалт ба вэб шалгагч

Жүжгийн зохиолч дээр суурилсан хоёр нэмэлт хэрэгсэл:

- **browser_playwright**: Хөтчийн бодит сешнүүдийг автоматжуулах — навигац хийх, товших, маягт бөглөх, өгөгдөл задлах, олон хуудасны урсгалыг зохицуулах. Толгойгүй эсвэл толгойтой ажилладаг.
- **жүжгийн зохиолч_инспектор**: Хөтөчийн шилжилтийг бүртгэж, алхам бүр дээр DOM агшин зуурын болон дэлгэцийн агшинг аваарай. Цаг хугацааны явцад вэб харилцан үйлчлэлийг дибаг хийх эсвэл хуудасны өөрчлөлтийг шалгахад хэрэгтэй.

### 🔄 Динамик хэрэгслийг ачаалж байна

"хэрэгслийн_каталог" болон "хэрэгслийн_ачаалах" нь танд хэрэглүүрийн үед хэрэглүүрийг нээж идэвхжүүлэх боломжийг олгоно.

uag **таны хиймэл оюун ухаан, таны машин, таны нөхцөлөөр байхыг эрмэлздэг.**

- SaaS хамааралгүй - орон нутагт ажилладаг
- Үйлчилгээ үзүүлэгчийн түгжээ байхгүй - хүссэн үедээ сэлгээрэй

Үнэгүй хиймэл оюун ухааны агентын туршлага, худалдагчийг түгжихгүй.

Realtime Дуу болон AEC3

## Realtime дуут горим нь бүрэн дуплекс микрофон болон чанга яригчийн оролт/гаралтыг дэмждэг. Хэрэв AEC3 арын хэсэг байхгүй бол uag автоматаар pywebrtc-audio суулгана.

**Бодит цагийн үйлчилгээ үзүүлэгчид**: OpenAI Realtime, Azure OpenAI GPT Realtime, Google Gemini Live, xAI Grok Voice болон Amazon Bedrock Nova Sonic. Bedrock-ийн хоёр чиглэлтэй урсгалын SDK-г зөвхөн Bedrock сонгосон үед автоматаар суулгана.

```bat
python scheck.py realtime
```

AEC3 нь микрофоны жинхэнэ дохио (ойролцоо) ба чанга яригч руу (хол) илгээсэн аудиог ашигладаг. Зөвхөн дууны асуудлыг судлах үед оношлогоог идэвхжүүлнэ.

```bat
set UAGENT_REALTIME_AUDIO_DEBUG=1
python scheck.py realtime
```

### OpenAI Realtime Function Calling

OpenAI Realtime нь аюулгүй байдлын хязгаарлагдмал Function Calling нэгдлийг дэмждэг. Одоогийн адаптер нь зөвхөн унших боломжтой get_current_time функцийг автоматаар харуулна. Хор хөнөөлтэй хэрэгсэл болон төхөөрөмжийн хяналт нь тодорхой зөвшөөрөгдсөн жагсаалт болон баталгаажуулалтын урсгалыг шаарддаг. Grok бодит цаг нь тусдаа адаптер ашигладаг бөгөөд энэ OpenAI-д хамаарах Function Calling замыг ашигладаггүй.
