# ИСПОЛЬЗОВАНИЕ (Параметры командной строки)

В данном документе описаны параметры командной строки, доступные для точек входа uag.

______________________________________________________________________

## Точки входа

| Команда | Модуль Python | Интерфейс |
|---|---|---|
| `uag` | `python -m uagent` | CLI (цикл stdin) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | Веб-сервер (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | сервер A2A HTTP |

______________________________________________________________________

## Параметры запуска CLI (`uag`)

### `--workdir` / `-C <path>`

Рабочий каталог. Если не указано, используется переменная окружения `UAGENT_WORKDIR`, а затем текущий каталог.
Каталог создаётся, если он не существует.

### `--tool-genre-mask <int>`

Битовая маска жанра инструмента. Если указана, интерактивный запрос на выбор жанра пропускается.

| Бит | Жанр | Описание |
|-----|-------|-------------|
| 1 | basic | Основные инструменты для работы с файлами и чатом |
| 2 | comm | Инструменты для общения (Bluesky, Teams) |
| 4 | office | Инструменты офисного пакета (Excel, PDF, PPTX) |
| 8 | devel | Инструменты разработки (git, lint, compile) |
| 16 | iot | Инструменты для устройств IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | Инструменты для выполнения команд |
| 64 | external | Инструменты для внешних плагинов |
| 128 | media | Генерация и анализ изображений/аудио |
| 256 | file | Инструменты управления файлами |
| 512 | index | Инструменты навигации по исходному коду и индексу |
| 1024 | dev | Инструменты для разработчиков и репозиториев |
| 2048 | web | Инструменты для веб-разработки и браузеров |
| 4096 | utility | Утилиты и вспомогательные инструменты |
| 8191 | all | Все инструменты |

Примеры:

```
uag --tool-genre-mask 1 # только базовые
uag --tool-genre-mask 9 # базовые + devel (1 + 8)
uag --tool-genre-mask 8191    # все инструменты
```

### `--use-tool` / `--no-use-tool`

Включает или отключает отправку определений инструментов в LLM. Переопределяет переменную среды `UAGENT_USE_TOOL`.

- `--use-tool` принудительно включает отправку определений инструментов.
- `--no-use-tool` принудительно отключает отправку определений инструментов.

При отключении LLM не получает определений инструментов и не может вызывать никакие инструменты.

### `--computer-use` / `--no-computer-use`

Включение или отключение функции «Использование компьютера». Переопределяет переменную среды `UAGENT_COMPUTER_USE`.

### `--inject-message` / `-M <message>`

Вставляет сообщение в LLM при запуске и завершает работу после выполнения. Это подразумевает использование параметра `--non-interactive`.

### `--embedded`

Встроенный режим для развертываний с ограничениями или требующих воспроизводимости.

- Отключает хранилище сеансов.
- Скрывает инструменты управления инструментами (`tool_catalog`, `tool_load`, `unload_tool`), если они явно не включены.
- Игнорирует `--tool-genre-mask`; для явной загрузки инструмента используйте `--enable-tool`.

### `--enable-tool <name>`

Явно загружает инструмент при запуске. Этот параметр можно повторять; также допускается указание нескольких имен, разделенных запятыми.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

Указанный порядок сохраняется и отражается в порядке инструментов, передаваемом в LLM. Явно включенные инструменты защищены от автоматической выгрузки.

### `--plugin-dir <path>`

Загрузить плагины из указанного каталога. Этот параметр можно повторять.

## Параметры, доступные только в CLI

### `--inject-message-auto <goal-options>`

Запустить автопилот из неинтерактивной вставленной цели. Значение использует те же опции, что и `:auto`; если значение содержит опции, его следует заключить в кавычки.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Сортировать элементы --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Сортировать элементы --infinite"
```

В обычном режиме используется путь, основанный на суждении рецензента. Установите `UAGENT_AUTO_SENTINEL=1`, чтобы включить режим с одним стражем LLM. В этом режиме целевой LLM должен заканчивать каждый ответ ровно одним из следующих маркеров:

- `<AUTO_CONTINUE>` — запустить следующий раунд
- `<AUTO_COMPLETE>` — успешно завершить

Отсутствие или неверность маркеров приводит к безопасной остановке автопилота. Целевой LLM по-прежнему запускается; просто не выполняется дополнительный вызов рецензента LLM.

### `--non-interactive`

Неинтерактивный режим. Цикл stdin не запускается. Если в качестве позиционного аргумента указан путь к файлу, он обрабатывается, и программа немедленно завершается.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## Параметры веб-сервера (`uagw`)

### `--host <address>`

Адрес привязки для веб-сервера (по умолчанию: `127.0.0.1`, можно переопределить с помощью `UAGENT_WEB_HOST`).

По умолчанию веб-сервер прослушивает только localhost (`127.0.0.1`). Чтобы сделать его доступным с других компьютеров в сети, используйте `--host 0.0.0.0`.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

Выбор жанров инструментов с использованием той же битовой маски, что описана выше. При указании этого параметра пропускается интерактивный запрос о жанре.

### `--use-tool` / `--no-use-tool`

Включает или отключает отправку определений инструментов в LLM. Переопределяет `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Включает или отключает использование компьютера. Переопределяет `UAGENT_COMPUTER_USE`.

### `--no-frontend`

Запускает только API без HTML-шаблонов или статических файлов интерфейса.

### `--embedded`

Отключает хранилище сеансов и скрывает инструменты управления инструментами (`tool_catalog`, `tool_load`, `unload_tool`).

## Параметры сервера A2A (`uaga`)

### `--host <address>`

Адрес привязки для сервера A2A HTTP (по умолчанию: `0.0.0.0`, может быть переопределён переменной `UAGENT_A2A_HOST`).

### `--port <число>`

Номер порта для сервера A2A HTTP (по умолчанию: `8765`, можно переопределить с помощью `UAGENT_A2A_PORT`).

### `--reload`

Включить «горячую» перезагрузку при изменениях кода (по умолчанию: отключено, можно переопределить с помощью `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

Выбор жанров инструментов с использованием битовой маски, описанной выше. Если этот параметр указан, интерактивный запрос о жанре пропускается.

### `--use-tool` / `--no-use-tool`

Включает или отключает отправку определений инструментов в LLM. Переопределяет `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Включение или отключение использования компьютера. Переопределяет `UAGENT_COMPUTER_USE`.

### `--embedded`

Отключает хранилище сеансов и скрывает инструменты управления инструментами (`tool_catalog`, `tool_load`, `unload_tool`).

## Связанные переменные среды

| Переменная | Описание |
|---|---|
| `UAGENT_PROVIDER` | Имя провайдера LLM (обязательно при запуске) |
| `UAGENT_*_API_KEY` | Ключ API для выбранного провайдера |
| `UAGENT_WORKDIR` | Рабочий каталог по умолчанию |
| `UAGENT_WEB_HOST` | Адрес привязки веб-сервера (по умолчанию: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | Адрес привязки сервера A2A (по умолчанию: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | Порт сервера A2A (по умолчанию: `8765`) |
| `UAGENT_A2A_RELOAD` | Включить «горячую» перезагрузку A2A по умолчанию |
| `UAGENT_USE_TOOL` | Отключить инструменты при значении `0`, `false`, `no` или `off` |
| `UAGENT_COMPUTER_USE` | Включить или отключить «Использование компьютера» по умолчанию |
| `UAGENT_SESSION_STORE` | Включить или отключить хранилище сеансов; Встроенный режим навязывает значение `0` |
| `UAGENT_PLUGIN_DIRS` | Дополнительные каталоги поиска плагинов |
| `UAGENT_AUTO_SENTINEL` | Включить режим автопилота-сентинела с одним LLM при значении `1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | Максимальное количество последовательных новых вызовов инструментов (по умолчанию: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | Максимальное количество раундов LLM на инструмент за одну операцию пользователя (по умолчанию: `200`) |
| `UAGENT_SHRINK_CNT` | Дополнительный порог автоматического сжатия сообщений (`0`/не задан = отключено) |
| `UAGENT_SHRINK_KEEP_LAST` | Количество сообщений, которые следует сохранить после сжатия (по умолчанию: `20`) |
| `UAGENT_LANG` | Язык интерфейса (`ja`, `en` и т. д.) |

Полный список переменных окружения см. в [ENVIRONMENT.md](ENVIRONMENT.md).

## Примеры

### Минимальный запуск с OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Локальный Ollama только с базовыми инструментами

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### Веб-сервер на всех интерфейсах

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

или

```
uagw --host 0.0.0.0
```

### Сервер A2A на localhost с настраиваемым портом

```
uaga --host 127.0.0.1 --port 8080
```

### Отключение инструментов для небольшой модели

```
uag --no-use-tool --tool-genre-mask 1
```

### Неинтерактивная обработка файлов

```
uag --non-interactive README.md
```
