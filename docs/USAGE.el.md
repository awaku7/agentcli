# ΧΡΗΣΗ (Επιλογές γραμμής εντολών)

Το παρόν έγγραφο περιγράφει τις επιλογές γραμμής εντολών που είναι διαθέσιμες για τα σημεία εισόδου uag.

______________________________________________________________________

## Σημεία εισόδου

| Εντολή | Μονάδα Python | Διεπαφή |
|---|---|---|
| `uag` | `python -m uagent` | CLI (βρόχος stdin) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | Διακομιστής ιστού (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | Διακομιστής A2A HTTP |

______________________________________________________________________

## Επιλογές εκκίνησης CLI (`uag`)

### `--workdir` / `-C <διαδρομή>`

Κατάλογος εργασίας. Εάν δεν οριστεί, χρησιμοποιείται η μεταβλητή περιβάλλοντος `UAGENT_WORKDIR` και, στη συνέχεια, ο τρέχων κατάλογος.
Ο κατάλογος δημιουργείται εάν δεν υπάρχει.

### `--tool-genre-mask <int>`

Μάσκα bit είδους εργαλείου. Όταν παρέχεται, παραλείπεται η διαδραστική προτροπή επιλογής κατηγορίας.

| Bit | Κατηγορία | Περιγραφή |
|-----|-------|-------------|
| 1 | basic | Βασικά εργαλεία αρχείων/συνομιλίας |
| 2 | comm | Εργαλεία επικοινωνίας (Bluesky, Teams) |
| 4 | office | Εργαλεία σουίτας γραφείου (Excel, PDF, PPTX) |
| 8 | devel | Εργαλεία ανάπτυξης (git, lint, compile) |
| 16 | iot | Εργαλεία συσκευών IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | Εργαλεία εκτέλεσης εντολών |
| 64 | external | Εργαλεία εξωτερικών προσθηκών |
| 128 | media | Δημιουργία και ανάλυση εικόνων/ήχου |
| 256 | file | Εργαλεία διαχείρισης αρχείων |
| 512 | index | Εργαλεία πλοήγησης σε πηγές/ευρετήρια |
| 1024 | dev | Εργαλεία προγραμματιστών και αποθετηρίων |
| 2048 | web | Εργαλεία ιστού και προγραμμάτων περιήγησης |
| 4096 | utility | Εργαλεία χρησιμότητας και υποστήριξης |
| 8191 | all | Όλα τα εργαλεία |

Παραδείγματα:

```
uag --tool-genre-mask 1 # μόνο βασικά
uag --tool-genre-mask 9 # βασικά + ανάπτυξη (1 + 8)
uag --tool-genre-mask 8191    # όλα τα εργαλεία
```

### `--use-tool` / `--no-use-tool`

Ενεργοποίηση ή απενεργοποίηση της αποστολής ορισμών εργαλείων στο LLM. Παρακάμπτει τη μεταβλητή περιβάλλοντος `UAGENT_USE_TOOL`.

- `--use-tool`: Ενεργοποιεί υποχρεωτικά την αποστολή εργαλείων.
- `--no-use-tool`: Απενεργοποιεί υποχρεωτικά την αποστολή εργαλείων.

Όταν είναι απενεργοποιημένη, το LLM δεν λαμβάνει ορισμούς εργαλείων και δεν μπορεί να καλέσει κανένα εργαλείο.

### `--computer-use` / `--no-computer-use`

Ενεργοποίηση ή απενεργοποίηση της χρήσης υπολογιστή. Παρακάμπτει τη μεταβλητή περιβάλλοντος `UAGENT_COMPUTER_USE`.

### `--inject-message` / `-M <message>`

Εισάγει ένα μήνυμα στο LLM κατά την εκκίνηση και τερματίζει μετά την ολοκλήρωση. Αυτό συνεπάγεται τη χρήση της επιλογής `--non-interactive`.

### `--embedded`

Λειτουργία ενσωμάτωσης για εγκαταστάσεις με περιορισμούς ή ευαίσθητες στην αναπαραγωγιμότητα.

- Απενεργοποιεί την αποθήκευση περιόδων λειτουργίας.
- Αποκρύπτει τα εργαλεία διαχείρισης εργαλείων (`tool_catalog`, `tool_load`, `unload_tool`) εκτός αν ενεργοποιηθούν ρητά.
- Αγνοεί την επιλογή `--tool-genre-mask`. Χρησιμοποιήστε την επιλογή `--enable-tool` για τη ρητή φόρτωση εργαλείων.

### `--enable-tool <name>`

Φορτώνει ρητά ένα εργαλείο κατά την εκκίνηση. Η επιλογή μπορεί να επαναληφθεί, ενώ γίνονται δεκτά και ονόματα διαχωρισμένα με κόμμα.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

Η καθορισμένη σειρά διατηρείται και αντικατοπτρίζεται στη σειρά των εργαλείων που παρουσιάζεται στο LLM. Τα εργαλεία που έχουν ενεργοποιηθεί ρητά δεν αποφορτώνονται αυτόματα.

### `--plugin-dir <path>`

Φόρτωση προσθηκών από τον καθορισμένο κατάλογο. Η επιλογή μπορεί να επαναληφθεί.

## Επιλογές μόνο για τη γραμμή εντολών

### `--inject-message-auto <goal-options>`

Εκκίνηση του αυτόματου πιλότου από έναν μη διαδραστικό εισαχθέντα στόχο. Η τιμή χρησιμοποιεί τις ίδιες επιλογές με το `:auto`· βάλτε σε εισαγωγικά την πλήρη τιμή όταν περιέχει επιλογές.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Ταξινόμηση των στοιχείων --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Ταξινόμηση των στοιχείων --infinite"
```

Η κανονική λειτουργία χρησιμοποιεί τη διαδρομή κρίσης του αναθεωρητή. Ορίστε `UAGENT_AUTO_SENTINEL=1` για να ενεργοποιήσετε τη λειτουργία ενός μόνο φρουρού LLM. Σε αυτή τη λειτουργία, ο στόχος LLM πρέπει να τερματίζει κάθε απόκριση με ακριβώς ένα από τα εξής:

- `<AUTO_CONTINUE>` — εκτέλεση ενός ακόμη γύρου
- `<AUTO_COMPLETE>` — επιτυχής ολοκλήρωση

Η απουσία ή η ύπαρξη μη έγκυρων δεικτών διακόπτει με ασφάλεια τον αυτόματο πιλότο. Το LLM-στόχο εξακολουθεί να εκτελείται· απλώς αποφεύγεται η πρόσθετη κλήση του LLM του αναθεωρητή.

### `--non-interactive`

Μη διαδραστική λειτουργία. Δεν ξεκινά τον βρόχο stdin. Εάν δοθεί διαδρομή αρχείου ως θεσιακό όρισμα, αυτή επεξεργάζεται και το πρόγραμμα τερματίζεται αμέσως.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## Επιλογές διακομιστή ιστού (`uagw`)

### `--host <address>`

Διεύθυνση σύνδεσης για τον διακομιστή ιστού (προεπιλογή: `127.0.0.1`, μπορεί να παρακαμφθεί από την μεταβλητή `UAGENT_WEB_HOST`).

Από προεπιλογή, ο διακομιστής ιστού ακούει μόνο στο localhost (`127.0.0.1`). Για να είναι προσβάσιμος από άλλους υπολογιστές στο δίκτυο, χρησιμοποιήστε `--host 0.0.0.0`.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

Επιλέξτε κατηγορίες εργαλείων χρησιμοποιώντας την ίδια μάσκα bit που περιγράφηκε παραπάνω. Όταν καθορίζεται, παραλείπεται η διαδραστική ερώτηση για την κατηγορία.

### `--use-tool` / `--no-use-tool`

Ενεργοποιήστε ή απενεργοποιήστε την αποστολή ορισμών εργαλείων στο LLM. Παρακάμπτει την παράμετρο `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Ενεργοποίηση ή απενεργοποίηση της χρήσης υπολογιστή. Παρακάμπτει την παράμετρο `UAGENT_COMPUTER_USE`.

### `--no-frontend`

Εκτελεί μόνο το API χωρίς πρότυπα HTML ή στατικά αρχεία frontend.

### `--embedded`

Απενεργοποιεί την αποθήκευση περιόδων λειτουργίας και αποκρύπτει τα εργαλεία διαχείρισης εργαλείων (`tool_catalog`, `tool_load`, `unload_tool`).

## Επιλογές διακομιστή A2A (`uaga`)

### `--host <address>`

Διεύθυνση σύνδεσης για τον διακομιστή A2A HTTP (προεπιλογή: `0.0.0.0`, μπορεί να αντικατασταθεί από το `UAGENT_A2A_HOST`).

### `--port <αριθμός>`

Αριθμός θύρας για τον διακομιστή A2A HTTP (προεπιλογή: `8765`, μπορεί να παρακαμφθεί από την παράμετρο `UAGENT_A2A_PORT`).

### `--reload`

Ενεργοποίηση της αυτόματης επαναφόρτωσης κατά την αλλαγή κώδικα (προεπιλογή: απενεργοποιημένη, μπορεί να παρακαμφθεί με τη μεταβλητή `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

Επιλέξτε κατηγορίες εργαλείων χρησιμοποιώντας τη μάσκα bit που περιγράφεται παραπάνω. Όταν καθορίζεται, παραλείπεται η διαδραστική προτροπή είδους.

### `--use-tool` / `--no-use-tool`

Ενεργοποίηση ή απενεργοποίηση της αποστολής ορισμών εργαλείων στο LLM. Παρακάμπτει την τιμή `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Ενεργοποίηση ή απενεργοποίηση της χρήσης υπολογιστή. Παρακάμπτει την `UAGENT_COMPUTER_USE`.

### `--embedded`

Απενεργοποιεί την αποθήκευση περιόδου λειτουργίας και κρύβει τα εργαλεία διαχείρισης εργαλείων (`tool_catalog`, `tool_load`, `unload_tool`).

## Σχετικές μεταβλητές περιβάλλοντος

| Μεταβλητή | Περιγραφή |
|---|---|
| `UAGENT_PROVIDER` | Όνομα παρόχου LLM (απαιτείται κατά την εκκίνηση) |
| `UAGENT_*_API_KEY` | Κλειδί API για τον επιλεγμένο πάροχο |
| `UAGENT_WORKDIR` | Προεπιλεγμένος κατάλογος εργασίας |
| `UAGENT_WEB_HOST` | Διεύθυνση σύνδεσης διακομιστή ιστού (προεπιλογή: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | Διεύθυνση σύνδεσης διακομιστή A2A (προεπιλογή: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | Θύρα διακομιστή A2A (προεπιλογή: `8765`) |
| `UAGENT_A2A_RELOAD` | Ενεργοποίηση της αυτόματης επαναφόρτωσης του A2A ως προεπιλογή |
| `UAGENT_USE_TOOL` | Απενεργοποίηση εργαλείων όταν η τιμή είναι `0`, `false`, `no` ή `off` |
| `UAGENT_COMPUTER_USE` | Ενεργοποίηση ή απενεργοποίηση της χρήσης υπολογιστή από προεπιλογή |
| `UAGENT_SESSION_STORE` | Ενεργοποίηση ή απενεργοποίηση του χώρου αποθήκευσης περιόδων λειτουργίας· η ενσωματωμένη λειτουργία επιβάλλει την τιμή `0` |
| `UAGENT_PLUGIN_DIRS` | Πρόσθετοι κατάλογοι αναζήτησης προσθηκών |
| `UAGENT_AUTO_SENTINEL` | Ενεργοποίηση της λειτουργίας αυτόματου ελέγχου «single-LLM» όταν η τιμή είναι `1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | Μέγιστος αριθμός διαδοχικών νέων κλήσεων εργαλείων (προεπιλογή: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | Μέγιστος αριθμός γύρων LLM/εργαλείου ανά λειτουργία χρήστη (προεπιλογή: `200`) |
| `UAGENT_SHRINK_CNT` | Προαιρετικό όριο αυτόματης συρρίκνωσης στα μηνύματα (`0`/μη ορισμένο = απενεργοποιημένο) |
| `UAGENT_SHRINK_KEEP_LAST` | Μηνύματα που θα διατηρηθούν μετά τη συρρίκνωση (προεπιλογή: `20`) |
| `UAGENT_LANG` | Γλώσσα διεπαφής (`ja`, `en`, κ.λπ.) |

Για τον πλήρη κατάλογο των μεταβλητών περιβάλλοντος, ανατρέξτε στο [ENVIRONMENT.md](ENVIRONMENT.md).

## Παραδείγματα

### Ελάχιστη εκκίνηση με OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Τοπικό Ollama μόνο με βασικά εργαλεία

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### Διακομιστής ιστού σε όλες τις διεπαφές

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

ή

```
uagw --host 0.0.0.0
```

### Διακομιστής A2A στον τοπικό υπολογιστή (localhost) με προσαρμοσμένη θύρα

```
uaga --host 127.0.0.1 --port 8080
```

### Απενεργοποίηση εργαλείων για ένα μικρό μοντέλο

```
uag --no-use-tool --tool-genre-mask 1
```

### Μη διαδραστική επεξεργασία αρχείων

```
uag --non-interactive README.md
```
