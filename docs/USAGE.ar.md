# الاستخدام (خيارات سطر الأوامر)

يصف هذا المستند خيارات سطر الأوامر المتاحة لنقاط الدخول uag.

______________________________________________________________________

## نقاط الدخول

| الأمر | وحدة Python | الواجهة |
|---|---|---|
| `uag` | `python -m uagent` | CLI (حلقة stdin) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | خادم الويب (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | خادم A2A HTTP |

______________________________________________________________________

## خيارات بدء التشغيل لـ CLI (`uag`)

### `--workdir` / `-C <path>`

دليل العمل. إذا لم يتم تعيينه، يتم الرجوع إلى متغير البيئة `UAGENT_WORKDIR`، ثم إلى الدليل الحالي.
يتم إنشاء الدليل إذا لم يكن موجودًا.

### `--tool-genre-mask <int>`

قناع بتات نوع الأداة. عند توفيرها، يتم تخطي موجه اختيار النوع التفاعلي.

| بت | النوع | الوصف |
|-----|-------|-------------|
| 1 | basic | أدوات الملفات/الدردشة الأساسية |
| 2 | comm | أدوات الاتصال (Bluesky، Teams) |
| 4 | office | أدوات حزمة المكتب (Excel، PDF، PPTX) |
| 8 | devel | أدوات التطوير (git، lint، compile) |
| 16 | iot | أدوات أجهزة إنترنت الأشياء (SwitchBot، ECHONET، Matter، UPnP) |
| 32 | exec | أدوات تنفيذ الأوامر |
| 64 | external | أدوات المكونات الإضافية الخارجية |
| 128 | media | إنشاء الصور/الصوت وتحليلها |
| 256 | file | أدوات إدارة الملفات |
| 512 | index | أدوات التنقل بين المصادر/الفهارس |
| 1024 | dev | أدوات المطورين والمستودعات |
| 2048 | web | أدوات الويب والمتصفح |
| 4096 | utility | أدوات المساعدة والدعم |
| 8191 | all | جميع الأدوات |

أمثلة:

```
uag --tool-genre-mask 1 # الأساسي فقط
uag --tool-genre-mask 9 # الأساسي + التطوير (1 + 8)
uag --tool-genre-mask 8191    # جميع الأدوات
```

### `--use-tool` / `--no-use-tool`

تمكين أو تعطيل إرسال تعريفات الأدوات إلى LLM. يتجاوز متغير البيئة `UAGENT_USE_TOOL`.

- `--use-tool` يُجبر على تشغيل إرسال الأدوات.
- `--no-use-tool` يُجبر على إيقاف إرسال الأدوات.

عند تعطيله، لا يتلقى LLM أي تعريفات للأدوات ولا يمكنه استدعاء أي أداة.

### `--computer-use` / `--no-computer-use`

تمكين أو تعطيل Computer Use. يتجاوز متغير البيئة `UAGENT_COMPUTER_USE`.

### `--inject-message` / `-M <message>`

إدراج رسالة في LLM عند بدء التشغيل والخروج بعد الانتهاء. وهذا يعني تفعيل `--non-interactive`.

### `--embedded`

الوضع المدمج لعمليات النشر المقيدة أو الحساسة للتكرار.

- يعطل مخزن الجلسات.
- يخفي أدوات إدارة الأدوات (`tool_catalog`، `tool_load`، `unload_tool`) ما لم يتم تمكينها صراحةً.
- يتجاهل `--tool-genre-mask`؛ استخدم `--enable-tool` لتحميل الأداة صراحةً.

### `--enable-tool <name>`

تحميل أداة بشكل صريح عند بدء التشغيل. يمكن تكرار الخيار، كما يُقبل إدخال الأسماء مفصولة بفواصل.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

يتم الحفاظ على الترتيب المحدد وينعكس في ترتيب الأدوات المعروض في LLM. يتم تثبيت الأدوات التي تم تمكينها صراحةً لمنع إزالتها تلقائيًا.

### `--plugin-dir <path>`

تحميل المكونات الإضافية من الدليل المحدد. يمكن تكرار هذا الخيار.

## خيارات CLI حصريًّا

### `--inject-message-auto <خيارات الهدف>`

بدء التشغيل التلقائي من هدف مُحقن غير تفاعلي. تستخدم القيمة نفس خيارات `:auto`؛ ضع القيمة الكاملة بين علامتي اقتباس عندما تحتوي على خيارات.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "فرز العناصر --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "فرز العناصر --infinite"
```

يستخدم الوضع العادي مسار تقدير المراجع. اضبط `UAGENT_AUTO_SENTINEL=1` للاشتراك في وضع الحارس الفردي LLM. في هذا الوضع، يجب أن ينهي الهدف LLM كل استجابة بواحد فقط من التالي:

- `<AUTO_CONTINUE>` — تشغيل جولة أخرى
- `<AUTO_COMPLETE>` — إنهاء بنجاح

تؤدي العلامات المفقودة أو غير الصالحة إلى إيقاف التشغيل التلقائي بأمان. ويستمر هذا في تشغيل الهدف LLM؛ بل إنه يتجنب فقط استدعاء المراجع الإضافي LLM.

### `--non-interactive`

الوضع غير التفاعلي. لا يبدأ حلقة stdin. إذا تم تقديم مسار ملف كحجة موضعية، يتم معالجته ويخرج البرنامج على الفور.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## خيارات خادم الويب (`uagw`)

### `--host <address>`

عنوان الربط لخادم الويب (الافتراضي: `127.0.0.1`، قابل للتجاوز بواسطة `UAGENT_WEB_HOST`).

بشكل افتراضي، يستمع خادم الويب إلى localhost فقط (`127.0.0.1`). لجعل الوصول إليه ممكنًا من أجهزة أخرى على الشبكة، استخدم `--host 0.0.0.0`.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

اختر أنواع الأدوات باستخدام قناع البتات نفسه الموصوف أعلاه. عند تحديدها، يتم تخطي المطالبة التفاعلية الخاصة بنوع الأداة.

### `--use-tool` / `--no-use-tool`

تمكين أو تعطيل إرسال تعريفات الأدوات إلى LLM. يتجاوز `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

تمكين أو تعطيل Computer Use. يتجاوز `UAGENT_COMPUTER_USE`.

### `--no-frontend`

تشغيل API فقط بدون قوالب HTML أو ملفات الواجهة الأمامية الثابتة.

### `--embedded`

تعطيل مخزن الجلسات وإخفاء أدوات إدارة الأدوات (`tool_catalog`، `tool_load`، `unload_tool`).

## خيارات خادم A2A (`uaga`)

### `--host <address>`

عنوان الربط لخادم A2A HTTP (الافتراضي: `0.0.0.0`، قابل للتجاوز بواسطة `UAGENT_A2A_HOST`).

### `--port <number>`

رقم المنفذ لخادم A2A HTTP (الافتراضي: `8765`، قابل للتجاوز بواسطة `UAGENT_A2A_PORT`).

### `--reload`

تمكين إعادة التحميل الفوري عند تغيير الكود (الافتراضي: معطل، قابل للتغيير بواسطة `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

اختيار أنواع الأدوات باستخدام قناع البتات الموصوف أعلاه. عند تحديدها، يتم تخطي موجه نوع الأداة التفاعلي.

### `--use-tool` / `--no-use-tool`

تمكين أو تعطيل إرسال تعريفات الأدوات إلى LLM. يتجاوز `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

تمكين أو تعطيل Computer Use. يتجاوز `UAGENT_COMPUTER_USE`.

### `--embedded`

تعطيل مخزن الجلسة وإخفاء أدوات إدارة الأدوات (`tool_catalog`, `tool_load`, `unload_tool`).

## متغيرات البيئة ذات الصلة

| المتغير | الوصف |
|---|---|
| `UAGENT_PROVIDER` | اسم موفر LLM (مطلوب عند بدء التشغيل) |
| `UAGENT_*_API_KEY` | مفتاح API للموفر المحدد |
| `UAGENT_WORKDIR` | دليل العمل الافتراضي |
| `UAGENT_WEB_HOST` | عنوان ربط خادم الويب (الافتراضي: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | عنوان ربط خادم A2A (الافتراضي: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | منفذ خادم A2A (الافتراضي: `8765`) |
| `UAGENT_A2A_RELOAD` | تمكين إعادة التحميل السريع لـ A2A بشكل افتراضي |
| `UAGENT_USE_TOOL` | تعطيل الأدوات عند ضبطها على `0` أو `false` أو `no` أو `off` |
| `UAGENT_COMPUTER_USE` | تمكين أو تعطيل Computer Use بشكل افتراضي |
| `UAGENT_SESSION_STORE` | تمكين أو تعطيل مخزن الجلسة؛ الوضع المدمج يفرض القيمة `0` |
| `UAGENT_PLUGIN_DIRS` | دلائل بحث إضافية للمكونات الإضافية |
| `UAGENT_AUTO_SENTINEL` | الاشتراك في وضع المراقبة التلقائية أحادي LLM عند ضبطه على `1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | الحد الأقصى لعدد المكالمات المتتالية للأدوات الحديثة (الافتراضي: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | الحد الأقصى لعدد جولات LLM/الأداة لكل عملية مستخدم (الافتراضي: `200`) |
| `UAGENT_SHRINK_CNT` | عتبة التقليص التلقائي الاختيارية في الرسائل (`0`/غير محددة = معطلة) |
| `UAGENT_SHRINK_KEEP_LAST` | عدد الرسائل المراد الاحتفاظ بها بعد التقليص (الافتراضي: `20`) |
| `UAGENT_LANG` | لغة الواجهة (`ja`، `en`، إلخ.) |

للاطلاع على القائمة الكاملة لمتغيرات البيئة، انظر [ENVIRONMENT.md](ENVIRONMENT.md).

## أمثلة

### البدء البسيط باستخدام OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Ollama محلي مع الأدوات الأساسية فقط

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### خادم الويب على جميع الواجهات

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

أو

```
uagw --host 0.0.0.0
```

### خادم A2A على المضيف المحلي (localhost) مع منفذ مخصص

```
uaga --host 127.0.0.1 --port 8080
```

### تعطيل الأدوات لنموذج صغير

```
uag --no-use-tool --tool-genre-mask 1
```

### معالجة الملفات بشكل غير تفاعلي

```
uag --non-interactive README.md
```
