# ВИКОРИСТАННЯ (Параметри командного рядка)

У цьому документі описано параметри командного рядка, доступні для точок входу uag.

______________________________________________________________________

## Точки входу

| Команда | Модуль Python | Інтерфейс |
|---|---|---|
| `uag` | `python -m uagent` | CLI (цикл stdin) |
| `uagg` | `python -m uagent.gui` | Графічний інтерфейс (tkinter) |
| `uagw` | `python -m uagent.web` | Веб-сервер (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | сервер A2A HTTP |

______________________________________________________________________

## Параметри запуску з командного рядка (`uag`)

### `--workdir` / `-C <шлях>`

Робочий каталог. Якщо не вказано, використовується змінна середовища `UAGENT_WORKDIR`, а потім — поточний каталог.
Каталог створюється, якщо його не існує.

### `--tool-genre-mask <int>`

Бітова маска жанру інструменту. Якщо вказано, запит на інтерактивний вибір жанру пропускається.

| Біт | Жанр | Опис |
|-----|-------|-------------|
| 1 | basic | Основні інструменти для роботи з файлами та чату |
| 2 | comm | Комунікаційні інструменти (Bluesky, Teams) |
| 4 | office | Інструменти офісного пакету (Excel, PDF, PPTX) |
| 8 | devel | Інструменти розробки (git, lint, compile) |
| 16 | iot | Інструменти для пристроїв IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | Інструменти виконання команд |
| 64 | external | Інструменти зовнішніх плагінів |
| 128 | media | Створення та аналіз зображень/аудіо |
| 256 | file | Інструменти управління файлами |
| 512 | index | Інструменти навігації по коду та індексу |
| 1024 | dev | Інструменти для розробників та репозиторіїв |
| 2048 | web | Інструменти для веб та браузерів |
| 4096 | utility | Утиліти та інструменти підтримки |
| 8191 | all | Усі інструменти |

Приклади:

```
uag --tool-genre-mask 1 # лише базові
uag --tool-genre-mask 9 # базові + розробка (1 + 8)
uag --tool-genre-mask 8191    # усі інструменти
```

### `--use-tool` / `--no-use-tool`

Увімкнення або вимкнення надсилання визначень інструментів до LLM. Перекриває значення змінної середовища `UAGENT_USE_TOOL`.

- `--use-tool` примусово вмикає надсилання інструментів.
- `--no-use-tool` примусово вимикає надсилання інструментів.

У разі вимкнення LLM не отримує визначень інструментів і не може викликати жодного інструменту.

### `--computer-use` / `--no-computer-use`

Увімкнення або вимкнення функції «Використання комп’ютера». Перекриває значення змінної середовища `UAGENT_COMPUTER_USE`.

### `--inject-message` / `-M <message>`

Вставляє повідомлення в LLM під час запуску та завершує роботу після виконання. Це передбачає використання параметра `--non-interactive`.

### `--embedded`

Вбудований режим для розгортань з обмеженнями або таких, що вимагають відтворюваності.

- Вимикає сховище сеансів.
- Приховує інструменти управління інструментами (`tool_catalog`, `tool_load`, `unload_tool`), якщо їх явно не ввімкнено.
- Ігнорує `--tool-genre-mask`; для явного завантаження інструментів використовуйте `--enable-tool`.

### `--enable-tool <name>`

Явно завантажує інструмент під час запуску. Цю опцію можна повторювати; також допускається вказівка імен, розділених комами.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

Зазначений порядок зберігається та відображається у порядку інструментів, що подається до LLM. Явно ввімкнені інструменти захищені від автоматичного вивантаження.

### `--plugin-dir <path>`

Завантажити плагіни із зазначеного каталогу. Цю опцію можна повторювати.

## Опції, доступні лише в командному рядку

### `--inject-message-auto <goal-options>`

Запустити автопілот із неінтерактивної вставленої цілі. Значення використовує ті самі параметри, що й `:auto`; якщо воно містить параметри, слід взяти повне значення в лапки.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Сортувати елементи --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Сортувати елементи --infinite"
```

У звичайному режимі використовується шлях, визначений на розсуд рецензента. Встановіть `UAGENT_AUTO_SENTINEL=1`, щоб увімкнути режим з однимLLM-сентинелом. У цьому режимі цільовий LLM повинен закінчувати кожну відповідь саме одним із таких маркерів:

- `<AUTO_CONTINUE>` — запустити ще один раунд
- `<AUTO_COMPLETE>` — успішно завершити

Відсутність або недійсні маркери безпечно зупиняють автопілот. Цей режим все одно запускає цільовий LLM; він лише уникає додаткового виклику рецензента LLM.

### `--non-interactive`

Неінтерактивний режим. Не запускає цикл stdin. Якщо шлях до файлу вказано як позиційний аргумент, він обробляється, і програма негайно завершується.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## Параметри веб-сервера (`uagw`)

### `--host <address>`

Адреса прив’язки для веб-сервера (за замовчуванням: `127.0.0.1`, можна змінити за допомогою `UAGENT_WEB_HOST`).

За замовчуванням веб-сервер прослуховує лише локальний хост (`127.0.0.1`). Щоб зробити його доступним з інших машин у мережі, використовуйте `--host 0.0.0.0`.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

Виберіть жанри інструментів, використовуючи ту саму бітову маску, що описана вище. Якщо вказано, інтерактивний запит щодо жанру пропускається.

### `--use-tool` / `--no-use-tool`

Увімкнути або вимкнути надсилання визначень інструментів до LLM. Перекриває значення `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Увімкнути або вимкнути використання комп’ютера. Перекриває `UAGENT_COMPUTER_USE`.

### `--no-frontend`

Запускає лише API без HTML-шаблонів або статичних файлів інтерфейсу.

### `--embedded`

Вимкнути сховище сеансів та приховати інструменти управління інструментами (`tool_catalog`, `tool_load`, `unload_tool`).

## Параметри сервера A2A (`uaga`)

### `--host <address>`

Адреса прив’язки для сервера A2A HTTP (за замовчуванням: `0.0.0.0`, можна перезаписати за допомогою `UAGENT_A2A_HOST`).

### `--port <число>`

Номер порту для сервера A2A HTTP (за замовчуванням: `8765`, можна змінити за допомогою `UAGENT_A2A_PORT`).

### `--reload`

Увімкнути гаряче перезавантаження при змінах коду (за замовчуванням: вимкнено, можна змінити за допомогою `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

Вибір жанрів інструментів за допомогою бітової маски, описаної вище. Якщо вказано, інтерактивний запит щодо жанру пропускається.

### `--use-tool` / `--no-use-tool`

Увімкнути або вимкнути надсилання визначень інструментів до LLM. Перекриває значення `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

Увімкнути або вимкнути використання комп’ютера. Перекриває значення `UAGENT_COMPUTER_USE`.

### `--embedded`

Вимкнути сховище сеансів та приховати інструменти управління інструментами (`tool_catalog`, `tool_load`, `unload_tool`).

## Пов’язані змінні середовища

| Змінна | Опис |
|---|---|
| `UAGENT_PROVIDER` | Назва постачальника LLM (обов’язкова при запуску) |
| `UAGENT_*_API_KEY` | Ключ LLM для обраного постачальника |
| `UAGENT_WORKDIR` | Робочий каталог за замовчуванням |
| `UAGENT_WEB_HOST` | Адреса прив’язки веб-сервера (за замовчуванням: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | Адреса прив’язки сервера A2A (за замовчуванням: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | Порт сервера A2A (за замовчуванням: `8765`) |
| `UAGENT_A2A_RELOAD` | Увімкнути гаряче оновлення A2A за замовчуванням |
| `UAGENT_USE_TOOL` | Вимкнути інструменти, якщо встановлено значення `0`, `false`, `no` або `off` |
| `UAGENT_COMPUTER_USE` | Увімкнути або вимкнути використання комп’ютера за замовчуванням |
| `UAGENT_SESSION_STORE` | Увімкнути або вимкнути сховище сеансів; У вбудованому режимі примусово встановлюється значення `0` |
| `UAGENT_PLUGIN_DIRS` | Додаткові каталоги для пошуку плагінів |
| `UAGENT_AUTO_SENTINEL` | Увімкнути режим автопілота-сентинела для одного LLM, якщо встановлено значення `1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | Максимальна кількість послідовних викликів нових інструментів (за замовчуванням: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | Максимальна кількість раундів LLM/інструмент на одну операцію користувача (за замовчуванням: `200`) |
| `UAGENT_SHRINK_CNT` | Опціональний поріг автоматичного стиснення повідомлень (`0`/не встановлено = вимкнено) |
| `UAGENT_SHRINK_KEEP_LAST` | Кількість повідомлень, які слід зберегти після стиснення (за замовчуванням: `20`) |
| `UAGENT_LANG` | Мова інтерфейсу (`ja`, `en` тощо) |

Повний перелік змінних середовища див. у [ENVIRONMENT.md](ENVIRONMENT.md).

## Приклади

### Мінімальний запуск із OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Локальний Ollama лише з базовими інструментами

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### Веб-сервер на всіх інтерфейсах

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

або

```
uagw --host 0.0.0.0
```

### Сервер A2A на localhost із власним портом

```
uaga --host 127.0.0.1 --port 8080
```

### Вимкнути інструменти для невеликої моделі

```
uag --no-use-tool --tool-genre-mask 1
```

### Неінтерактивна обробка файлів

```
uag --non-interactive README.md
```
