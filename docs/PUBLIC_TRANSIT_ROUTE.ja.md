# 公共交通機関の経路探索

`public_transit_route` は、Yahoo!路線情報を使って日本の鉄道、バス、航空、フェリーなどの公共交通機関の経路を検索します。

## 入力

- `origin`: 駅、バス停、住所、施設。`郡山` のように候補が複数ある駅名は、到着地の地域に応じて駅を補正する場合があります（例：堺筋本町なら `郡山(奈良県)`）。
- `destination`: 駅、バス停、住所、施設
- `departure`: 任意のローカル時刻（ISO 8601形式）
- `max_routes`: 候補経路数（1〜6、既定値3）
- `sort_by`: `recommended`、`fastest`、`cheapest`、`fewest_transfers`
- `ticket`: `ic` または `normal`
- `avoid`: `shinkansen`、`limited_express`、`airline`、`highway_bus`、`local_bus`、`ship`

## 出力

候補ごとに、出発・到着時刻、所要時間、乗換回数、円単位の運賃、運賃詳細、距離、区間、行程を返します。Yahoo!路線情報から支払い単位を特定できる場合は、`fare_breakdown` に交通機関ごとの内訳を返します。各項目には `operator`、`unit`、`label`、`amount_yen` が含まれます。たとえば、JR運賃と大阪メトロ運賃を別々に表示できます。`fare_yen` は候補全体の合計運賃です。Yahoo!路線情報の出典URL、検索クエリを保持したMarkdown形式の `source_link`、取得時刻、`fare_type: web_checked` も含みます。

たとえば、郡山（奈良県）から堺筋本町への経路では、JRと大阪メトロをそれぞれ支払う内訳を取得できます。内訳はYahoo!路線情報の表示に基づく参考情報であり、支払い処理を行うものではありません。また、全区間を1枚の乗車券で利用できることを保証するものでもありません。

経路と運賃はYahoo!路線情報が提供する情報であり、変更される場合があります。時間に余裕のない移動では、実際の公式情報を確認してください。

## 利用上の注意

駅名の曖昧性判定には、国土交通省 国土数値情報 N02 鉄道データ（令和6年）から生成した駅マスターを使用します。出典と利用約款は `src/uagent/tools/data/jp_stations.meta.json` に記録しています。駅マスターは最新状態を保証しないため、最終的な経路・駅名はYahoo!路線情報の検索結果で確認します。

ネットワーク接続が必要で、Yahoo!路線情報の公開Web検索結果を利用します。Yahoo!/LINEヤフーの利用規約、robotsルール、レート制限、帰属表示の要件を遵守し、節度を持って利用してください。公式Yahoo APIクライアントではありません。
