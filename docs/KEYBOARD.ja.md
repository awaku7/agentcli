# CLI キーボード操作

対話型 CLI（`uag`）のキー操作です。断りがない限り、標準の全画面表示でも従来画面（`UAGENT_CLI_VIEW=0`）でも同じです。

## 送信

| キー | 動作 |
| --- | --- |
| Enter | 入力した行を送る |
| Ctrl+J | 改行を入れる（複数行の文を書く。全画面表示のみ。従来画面では Enter と同じく送信になる） |
| 貼り付け（Ctrl+V や右クリックなど、端末による） | 文字が入るだけ。Enter を押すまで送らない |

エージェントの作業中も、全画面表示では入力欄がそのまま使えます。

- 文を書いて Enter を押すと、どうするか聞かれます。もう一度 Enter（または `y`）で応答を止めてすぐ送り、`n` で次のターンへの待ち行列に入れます。Esc や Ctrl+C でも待ち行列に入ります。
- `:` で始まる行はコマンドとして、聞かれずに待ち行列に入ります。
- 待ち行列の文は出力欄に「送信待ち」として出て、順番に送られます。

長い文をエディタで書くときは、`f` だけの行を送ります。エディタでは Ctrl+X で送信、Esc でキャンセルです。

## 入力欄の編集

入力欄は Emacs 式の編集キーです。

| キー | 動作 |
| --- | --- |
| Ctrl+A / Ctrl+E | 行の先頭 / 末尾へ |
| Ctrl+B / Ctrl+F | 1文字 左 / 右へ |
| Alt+B / Alt+F（または Esc のあと B / F） | 1単語 左 / 右へ |
| Ctrl+K | カーソルから行の末尾まで消す |
| Ctrl+U | カーソルから行の先頭まで消す |
| Ctrl+W、または Alt+Backspace | カーソルの前の単語を消す |
| Ctrl+Y | 最後に消した文字を戻す |
| Ctrl+T | カーソルの前後の文字を入れ替える |
| Ctrl+_ | 直前の編集を元に戻す |
| Ctrl+L | 画面を描き直す |

## 補完

- Tab で補完メニューが開きます。`:` コマンド、ファイルのパスなど、入力中の言葉への候補が出ます。
- 候補は、打っている途中でも自動で出ます。
- メニュー内では 上 / 下 で移動し、Tab で候補を確定します。Enter は候補の確定だけでは済まず、その時点の入力がそのまま送られます。候補を選んで続きを書くとき（コマンドの引数を足すときなど）は Tab を使ってください。

## 入力の履歴

- 入力欄で 上 / 下 を押すと、前に送った文をたどれます。
- 全画面表示では Ctrl+R の履歴検索は使えません。

## 出力を読む（全画面表示）

| キー / 操作 | 動作 |
| --- | --- |
| PageUp / PageDown | 出力欄をスクロール |
| マウスホイール | 出力欄をスクロール（ポインタの位置はどこでも可） |
| マウスでドラッグ | 出力の文字を選ぶ。ボタンを離すとクリップボードにコピーされる。上下の端にポインタを置いたままにすると、選びながらスクロールが続く |

## 停止と終了

| キー | 動作 |
| --- | --- |
| F12 | 実行中の応答を止める（オートパイロットも止まる） |
| Ctrl+C | 応答の実行中は応答を止める。質問が出ているときは質問を取り消す。何も起きていないときは CLI を終了する |
| Ctrl+D | 入力欄が空のとき、CLI を終了する |

## 質問への回答

エージェントが質問することがあります。確認、選択肢、パスワードなどです。全画面表示では画面は切り替わりません。質問は出力に残り、上の罫線に `[REPLY]`（パスワードのときは `[PASSWORD]`）と出て、答えはいつもの入力欄に打ちます。

- Enter で答えを送ります。Ctrl+C で質問を取り消します。
- 質問が出たときに書きかけだった文は、答え終わると戻ってきます。
- パスワードの答えは打つ間 `*` で隠れます。入力の履歴には残りません。元に戻す操作や切り取り、マクロなど、文字を他へ運ぶ編集キーでもパスワードは戻りません。
- 長い答えには、`f` だけの行を送ると複数行エディタが開きます（Ctrl+X で送信、Esc でキャンセル）。

## キーボードマクロ

マクロはキーの入力列を記録して、あとで再生する機能です。同じ操作を何度も繰り返すときに使えます。

| キー | 動作 |
| --- | --- |
| Ctrl+X ( | 記録を始める |
| Ctrl+X ) | 記録を止める |
| Ctrl+X e | 記録したキーを再生する |

例: Ctrl+X ( を押し、`:cd src` と打って Enter、Ctrl+X ) を押します。以後は Ctrl+X e で同じ入力が繰り返されます。

マクロはそのセッションの中だけ有効で、CLI を終了すると消えます。残るのは最後の1つだけです。新しく記録すると前のものは置き換わります。パスワードの質問に答えている間は記録が止まり、答えている間に記録されたものは捨てられます。パスワードがマクロに入ることはありません。
