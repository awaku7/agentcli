## কেন uag?

**বিক্রেতা লক-ইন থেকে বিরত থাকুন।** বেশিরভাগ AI সহকারী আপনাকে একটি নির্দিষ্ট প্রদানকারী বা ক্লাউড পরিষেবার সাথে সংযুক্ত করে। uag আলাদা।

- **স্থানীয়ভাবে চলে** আপনার মেশিনে। আপনার ডেটা আপনার সাথে থাকে (আপনি যে APIটি কল করেন তা ছাড়া)।
- **প্রদানকারীর স্বাধীনতা**: OpenAI, Claude, Gemini, DeepSeek, Ollama, Azure, Bedrock, Novita, HuggingFace... 24 প্রদানকারী, সব একটি একক ইন্টারফেস থেকে অ্যাক্সেসযোগ্য। এনভায়রনমেন্ট ভেরিয়েবল পুনঃকনফিগার করে তাদের মধ্যে অদলবদল করুন — কোন রিইন্সটল, কোন মাইগ্রেশন নেই।
- **222 টুল**: ফাইল I/O, ওয়েব সার্চ, ইমেজ জেনারেশন, Gmail, BLE ডিভাইস স্ক্যানিং, MCP সার্ভার ইন্টিগ্রেশন — \*\*130 স্ট্যাটিকভাবে সমান্তরাল-নিরাপদ \*\* চিহ্নিত করা হয়েছে `UAGENT_PARALLEL_WORKERS`)। যখন LLM একবারে একাধিক টুল কল ফায়ার করে, তখন uag স্বয়ংক্রিয়ভাবে সেগুলিকে সমান্তরাল করে। একই ইঞ্জিন, যেকোনো ইন্টারফেস।
- **IoT প্রস্তুত**: SwitchBot, ECHONET Lite, Matter, UPnP — AI এর মাধ্যমে আপনার হোম ডিভাইসগুলি নিয়ন্ত্রণ করুন।
- **এজেন্ট দক্ষতা**: মার্কেটপ্লেস থেকে কমিউনিটি-বিল্ট দক্ষতা ইনস্টল করুন। uagকে অবিরামভাবে প্রসারিত করুন।

uag হল **আপনার শর্তাবলীতে আপনার AI সহকারী**। একটি প্রদানকারীর সাথে আবদ্ধ নয়, একটি ইন্টারফেসের সাথে আবদ্ধ নয়, একটি প্ল্যাটফর্মের সাথে আবদ্ধ নয়৷

## Computer Use

Computer Use অপ্ট-ইন করে এবং একটি দৃশ্যমান Playwright ব্রাউজার রানটাইম
এবং একটি ডেস্কটপ রানটাইম উভয়কেই সমর্থন করে৷ সক্রিয় করা হলে, উভয় রানটাইম তৈরি এবং নিবন্ধিত হয়; 
নির্বাচিত রানটাইম `UAGENT_COMPUTER_ENVIRONMENT` দ্বারা নিয়ন্ত্রিত হয়: 

``bat
set UAGENT_COMPUTER_USE=1
সেট UAGENT_COMPUTER_ENVIRONMENT=ব্রাউজার
`Os`কে টপকে দে`সেকে ডিস্ক করতে পরিবর্তে রানটাইম। স্বাভাবিক প্রস্থান, `Ctrl-C`, এবং প্রক্রিয়া শাটডাউনে Runtime সংস্থানগুলি একসাথে বন্ধ করা হয়। ব্রাউজার-ভিত্তিক CI বা ধোঁয়া পরীক্ষার জন্য
`UAGENT_COMPUTER_HEADLESS=1` সেট করুন। 
একীকরণ এবং নিরাপত্তা বিশদ বিবরণের জন্য [docs/COMPUTER_USE_IMPLEMENTATION.md](docs/COMPUTER_USE_IMPLEMENTATION.md)
দেখুন।

## রিয়েলটাইম ভয়েস এবং AEC3

 রিয়েলটাইম ভয়েস মোড OpenAI রিয়েলটাইম, Azure OpenAI GPT রিয়েলটাইম, xAI Grok ভয়েস API, Google Gemini মাল্টিমোডাল লাইভ API, এবং অ্যামাজন বেডরক এবং মাইক্রোফোনের সাথে আমাজন বেডরক এবং ফুল-আপ নোভা-আপ স্পিক সমর্থন করে। প্রয়োজনীয় `pywebrtc-audio` AEC3 ব্যাকএন্ড স্বয়ংক্রিয়ভাবে ইনস্টল করা হয়, এবং বেডরকের ঐচ্ছিক দ্বিমুখী-স্ট্রিমিং SDK শুধুমাত্র তখনই স্বয়ংক্রিয়ভাবে ইনস্টল করা হয় যখন বেডরক প্রদানকারী নির্বাচন করা হয়:

``bash
python scheck.py realtime
```

AEC3 পাইপলাইনে অডিও প্রাপ্ত করার জন্য অ্যাক্টিভ সাইন ইন করা হয় স্পিকার (\`দূর') যাতে সহকারী কথা বলার সময় শুনতে পারে। অডিও সমস্যাগুলি তদন্ত করার সময় শুধুমাত্র ডায়াগনস্টিকস সক্ষম করুন:

\`\`bat
set UAGENT_REALTIME_AUDIO_DEBUG=1
python scheck.py realtime

```

### OpenAI রিয়েলটাইম ফাংশন কলিং

OpenAI-এ ফান টেগিং-এর নিরাপত্তা সহায়তা বর্তমান রিয়েলটাইম অ্যাডাপ্টার শুধুমাত্র পঠনযোগ্য `get_current_time` স্বয়ংক্রিয়ভাবে প্রকাশ করে। ধ্বংসাত্মক সরঞ্জাম এবং ডিভাইস নিয়ন্ত্রণ একটি সুস্পষ্ট অনুমোদিত তালিকা এবং নিশ্চিতকরণ ফ্লো ছাড়া প্রকাশ করা হয় না। Grok রিয়েলটাইম একটি পৃথক অ্যাডাপ্টার ব্যবহার করে এবং এই OpenAI-নির্দিষ্ট ফাংশন-কল পাথ ব্যবহার করে না৷

### ⚡ সমান্তরাল টুল এক্সিকিউশন

 যখন LLM একই সাথে একাধিক টুলের অনুরোধ করে, uag **স্বয়ংক্রিয়ভাবে 
01 টুল চিহ্নিত করা হয়। `x_parallel_safe` এবং `ThreadPoolExecutor` এর মাধ্যমে একই সাথে চালান (ডিফল্টভাবে 8টি থ্রেড; পরিবর্তন করতে `UAGENT_PARALLEL_WORKERS` সেট করুন)। সমান্তরালভাবে চালান → একটি ব্যাচে সংগৃহীত ফলাফল। 

 বর্তমান গণনা টুল মডিউলের উপর ভিত্তি করে যা একটি `TOOL_SPEC` সংজ্ঞায়িত করে (বর্তমানে 222, `src/uagent/tools_rust/`-এ 2টি মরিচা-সমর্থিত সরঞ্জাম সহ)। `http_request` পদ্ধতি-সংবেদনশীল নিরাপত্তা ব্যবহার করে: `GET`/`HEAD`/`OPTIONS` কলগুলি সমান্তরালভাবে চলতে পারে, যখন লেখার পদ্ধতিগুলি সিরিয়াল থাকে।

 ফ্লাইতে uag-এর সক্ষমতা ইনস্টল করুন এবং প্রসারিত করুন। জটিল, বহু-পদক্ষেপের কাজগুলির জন্য উপযুক্ত যেগুলির পুনরাবৃত্তিমূলক পরিমার্জন প্রয়োজন। 

- **এটি কীভাবে কাজ করে**: প্রতিটি রাউন্ডে একটি প্রধান প্রশ্ন (ধাপ A) এর পরে একটি পর্যালোচক রায় (ধাপ B) থাকে যা সিদ্ধান্ত নেয় "সম্পূর্ণ না চালিয়ে যান?" 
- **একই প্রদানকারী, একই কোড ব্যবহার করে: API ** মূল পর্যালোচনার কোডটি ব্যবহার করে ক্যোয়ারী — প্রতিক্রিয়া সহ API সমর্থন।
- **পৃথক বিচারক LLM** (ঐচ্ছিক): পর্যালোচকের জন্য একটি ভিন্ন প্রদানকারী/মডেল ব্যবহার করতে `UAGENT_AP_PROVIDER` সেট করুন (উদাঃ বিচারের জন্য একটি সস্তা মডেল ব্যবহার করুন)। অথবা লক্ষ্য পূরণ হলে পর্যালোচককে সিদ্ধান্ত নিতে দিন। 
- **কনফিগারযোগ্য**: বাজেট নিয়ন্ত্রণ করতে `--max-rounds N`। ব্যাচ স্টেট ম্যানেজার

uag দীর্ঘ-চলমান মাল্টি-ফাইল টাস্ক জুড়ে অগ্রগতি ট্র্যাক করতে পারে৷ যখন LLM ডজন ডজন ফাইল প্রসেস করে, তখন `batch_state` ডিস্কে মুলতুবি থাকা, সম্পন্ন করা এবং ব্যর্থ ফাইলগুলির তালিকা বজায় রাখে। সেশন শেষ হলে বা রাউন্ড টাইম শেষ হলে, পরবর্তী রানটি যেখানে থামানো হয়েছিল সেখান থেকে আবার শুরু হবে — কিছুই হারিয়ে যাবে না। আপনি নিয়ন্ত্রণে থাকুন। ইন্টারফেস | কিভাবে বাধা দিতে হয় |
|---|---|
| **CLI** | LLM স্ট্রিমিংয়ের সময় `c` কী টিপুন — বর্তমান প্রতিক্রিয়া বন্ধ হয়ে যায়, এবং `"স্টপ"` একটি ব্যবহারকারীর বার্তা হিসাবে পাঠানো হয় যাতে LLM সেই অনুযায়ী প্রতিক্রিয়া জানায় |
