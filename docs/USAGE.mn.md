# ХЭРЭГЛЭЭ (Мөр тушаалын сонголтууд)

Энэхүү баримт бичиг нь uag нэвтрэх цэгүүдийн хувьд боломжтой мөр тушаалын сонголтуудыг тайлбарлана.

______________________________________________________________________

## Оролт цэгүүд

| Тушлага | Python модуль | Интерфейс |
|---|---|---|
| `uag` | `python -m uagent` | CLI (stdin цикл) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | Вэб сервер (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | A2A HTTP server |

______________________________________________________________________

## CLI эхлүүлэх тохиргоо (`uag`)

### `--workdir` / `-C <path>`

Ажлын директори. Хэрэв тохируулаагүй бол `UAGENT_WORKDIR` орчны хувьсагчид, дараа нь одоогийн директорид ухрана.
Директори байхгүй бол үүсгэнэ.

### `--tool-genre-mask <int>`

Онолын төрөл жанрын битмаск. Өгөгдсөн тохиолдолд интерактив төрөл сонгох уриалгыг алгасдаг.

| Бит | Жанр | Тайлбар |
|-----|-------|-------------|
| 1 | basic | Анхан шатны файл/чат хэрэгслүүд |
| 2 | comm | Харилцаа холбооны хэрэгслүүд (Bluesky, Teams) |
| 4 | office | Оффисын багц хэрэгслүүд (Excel, PDF, PPTX) |
| 8 | devel | Хөгжүүлэлтийн хэрэгслүүд (git, lint, compile) |
| 16 | iot | IoT төхөөрөмжийн хэрэгслүүд (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | Тушаал гүйцэтгэх хэрэгслүүд |
| 64 | external | Гадаад залгаасуудын хэрэгслүүд |
| 128 | media | Зураг/дуу үүсгэх, шинжлэх |
| 256 | file | Файл удирдах хэрэгслүүд |
| 512 | index | Эх код/индекс навигацийн хэрэгслүүд |
| 1024 | dev | Хөгжүүлэгч ба репозиторийн хэрэгслүүд |
| 2048 | web | Вэб ба хөтөчийн хэрэгслүүд |
| 4096 | utility | Туслах ба дэмжлэгийн хэрэгслүүд |
| 8191 | all | Бүх хэрэгслүүд |

Жишээнүүд:

```
uag --tool-genre-mask 1 # зөвхөн суурь
uag --tool-genre-mask 9 # суурь + хөгжүүлэлт (1 + 8)
uag --tool-genre-mask 8191    # бүх хэрэгсэл
```

### `--use-tool` / `--no-use-tool`

LLM руу хэрэгслийн тодорхойлолтыг илгээхийг асаах эсвэл унтраах. `UAGENT_USE_TOOL` орчны хувьсагчийг дарах.

- `--use-tool` хэрэгслийн илгээлтийг заавал асаана.
- `--no-use-tool` хэрэгслийн илгээлтийг заавал унтраана.

Унтраасан үед LLM ямар ч хэрэгслийн тодорхойлолт хүлээн авахгүй бөгөөд ямар ч хэрэгслийг дуудаж чадахгүй.

### `--computer-use` / `--no-computer-use`

Computer Use-ийг асаах эсвэл унтраах. `UAGENT_COMPUTER_USE` орчны хувьсагчийг давуулан тогтоодог.

### `--inject-message` / `-M <message>`

Эхлэх үед LLM-д мессеж оруулах ба дууссаны дараа гардаг. Энэ нь `--non-interactive` тохиргоог агуулна.

### `--embedded`

Хязгаарлагдмал эсвэл дахин үйлдвэрлэх чадварт мэдрэг байршуулгад зориулсан суулгасан горим.

- Сессийн санг идэвхгүй болгоно.
- Хэрэгслийн удирдлагын хэрэгслүүд (`tool_catalog`, `tool_load`, `unload_tool`) ил тод идэвхжүүлээгүй бол харуулдаггүй.
- `--tool-genre-mask` тохиргоог үл тоомсорлодог; тодорхой хэрэгслийг ачаалахын тулд `--enable-tool` ашиглана.

### `--enable-tool <name>`

Эхлүүлэх үед тодорхой нэг хэрэгслийг ачаална. Энэ сонголтыг давтан ашиглаж болох ба нэрсийг таслалаар тусгаарласан тохиолдолд ч хүлээн авна.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

Заагдсан дарааллыг хадгалж, LLM-д үзүүлэх багажийн дараалалд тусгагддаг. Ил тодорхой идэвхжүүлсэн багаж хэрэгслүүд автоматаар ачаалагдахаас хамгаалагддаг.

### `--plugin-dir <path>`

Заагдсан директориос плагинуудыг ачаална. Энэхүү сонголтыг давтан ашиглаж болно.

## CLI-д зориулсан сонголтууд

### `--inject-message-auto <goal-options>`

Хэрэглэгчийн оролцоогүйгээр автомат гоалыг эхлүүлнэ. Үнэ нь `:auto`-гийн адил сонголтуудыг ашиглана; сонголтууд агуулсан тохиолдолд бүхэл утгыг иш татаж бичнэ.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --infinite"
```

Ердийн горим нь хянан үзэгчийн шийдвэрлэх замыг ашиглана. Нэг LLM-ийн sentinel горимд орохын тулд `UAGENT_AUTO_SENTINEL=1` гэж тохируулна. Энэ горимд зорилтот LLM нь хариу бүрийг яг нэгээр нь дараах байдлаар дуусгах ёстой:

- `<AUTO_CONTINUE>` — дараагийн тойргоор үргэлжлүүлэх
- `<AUTO_COMPLETE>` — амжилттай дуусгах

Маркер дутуу эсвэл буруу байх тохиолдолд автомат горим аюулгүйгээр зогсдог. Энэ нь зорилтот LLM-ыг гүйцэтгэсээр байдаг; зөвхөн нэмэлт шүүмжлэгч LLM-ын дуудлагыг зайлуулдаг.

### `--non-interactive`

Харилцан идэвхгүй горим. stdin циклийг эхлүүлдэггүй. Хэрэв байрлалын аргумент болгон файл замыг өгвөл, тэр замыг боловсруулж, хөтөлбөр даруй гарна.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## Вэб серверийн тохиргоо (`uagw`)

### `--host <address>`

Вэб серверийн холбох хаяг (анхдагч: `127.0.0.1`, `UAGENT_WEB_HOST`-аар өөрчилж болно).

Анхдагчаар вэб сервер зөвхөн localhost дээр сонсоно (`127.0.0.1`). Сүлжээнд холбогдсон бусад машин дээрээс хандах боломжтой болгохын тулд `--host 0.0.0.0` ашиглана.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

Дээр дурдсан ижил битмаск ашиглан хэрэгслийн төрөл жанрыг сонгоно. Заасан тохиолдолд интерактив төрөл сонгох асуулгыг алгасдаг.

### `--use-tool` / `--no-use-tool`

LLM руу хэрэгслийн тодорхойлолтыг илгээхийг идэвхжүүлэх эсвэл идэвхгүйжүүлэх. `UAGENT_USE_TOOL`-г давуулан тогтоодог.

### `--computer-use` / `--no-computer-use`

Computer Use-ийг идэвхжүүлэх эсвэл идэвхгүйжүүлэх. `UAGENT_COMPUTER_USE`-ыг давах.

### `--no-frontend`

HTML загвар болон статик фронтэнд файлуудыг ашиглахгүйгээр зөвхөн API-ыг ажиллуулна.

### `--embedded`

Сессийн хадгалах сангийн үйлдлийг идэвхгүй болгож, хэрэгслийн удирдлагын хэрэгслүүдийг (`tool_catalog`, `tool_load`, `unload_tool`) нууна.

## A2A серверийн тохиргоо (`uaga`)

### `--host <address>`

A2A HTTP серверийн холбох хаяг (анхдагч: `0.0.0.0`, `UAGENT_A2A_HOST`-ээр өөрчилж болно).

### `--port <тоо>`

A2A HTTP серверийн порт дугаар (анхдагч: `8765`, `UAGENT_A2A_PORT`-ээр өөрчилж болно).

### `--reload`

Кодын өөрчлөлтөд халуун дахин ачаалгыг идэвхжүүлэх (анхдагч: унтарсан, `UAGENT_A2A_RELOAD`-ээр дарах боломжтой).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

Дээр дурдсан ижил битмаск ашиглан хэрэгслийн төрөл жанрыг сонгоно. Заасан тохиолдолд интерактив жанрын асуултыг алгасдаг.

### `--use-tool` / `--no-use-tool`

Оролтын хэрэгслийн тодорхойлолтыг LLM рүү илгээхийг идэвхжүүлэх эсвэл идэвхгүйжүүлэх. `UAGENT_USE_TOOL`-ийг дарах.

### `--computer-use` / `--no-computer-use`

Computer Use-ыг идэвхжүүлэх эсвэл идэвхгүйжүүлэх.

`UAGENT_COMPUTER_USE`-ыг дарах.

### `--embedded`

Сессийн хадгалах сангийн үйлчлэлийг зогсоож, хэрэгсэл удирдах хэрэгслүүдийг (`tool_catalog`, `tool_load`, `unload_tool`) нууна.

## Холбогдох орчны хувьсагчид

| Хувьсагч | Тайлбар |
|---|---|
| `UAGENT_PROVIDER` | LLM үйлчилгээ үзүүлэгчийн нэр (ажиллаж эхлэхэд шаардлагатай) |
| `UAGENT_*_API_KEY` | сонгосон үйлчилгээ үзүүлэгчийн түлхүүр |
| `UAGENT_WORKDIR` | анхдагч ажиллах директори |
| `UAGENT_WEB_HOST` | Вэб серверийн холболтын хаяг (анхдагч: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A серверийн холболтын хаяг (анхдагч: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | A2A серверийн порт (анхдагч: `8765`) |
| `UAGENT_A2A_RELOAD` | Анхдагчаар A2A халуун дахин ачаалгыг идэвхжүүлэх |
| `UAGENT_USE_TOOL` | `0`, `false`, `no` эсвэл `off` гэж тохируулсан үед хэрэгслийг идэвхгүй болгоно |
| `UAGENT_COMPUTER_USE` | Computer Use-ийг анхдагчаар идэвхжүүлэх эсвэл идэвхгүйжүүлэх |
| `UAGENT_SESSION_STORE` | сессийн хадгалах сангийн идэвхжүүлэлт/идэвхгүйжүүлэлт; Суулгасан горим нь `0` болгодог |
| `UAGENT_PLUGIN_DIRS` | Нэмэлт плагин хайлтын директориуд |
| `UAGENT_AUTO_SENTINEL` | `1` болгоход ганц LLM автопилот сэнтинел горимд оролцох |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | Дараалсан шинэ хэрэгслийн дуудлагын дээд хязгаар (анхны тохиргоо: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | Хэрэглэгчийн үйлдэл тутамд хамгийн их LLM/tool тойрог (анхны байрлал: `200`) |
| `UAGENT_SHRINK_CNT` | Мессежүүдийн сонголттой авто-шахалтын босго (`0`/тогтоогоогүй = идэвхгүй) |
| `UAGENT_SHRINK_KEEP_LAST` | Шахалтын дараа хадгалах мессежүүд (анхдагч: `20`) |
| `UAGENT_LANG` | Холбоо барих хэл (`ja`, `en`, гэх мэт) |

Бүх орчны хувьсагчдын бүрэн жагсаалтыг [ENVIRONMENT.md](ENVIRONMENT.md)-ээс үзнэ үү.

## Жишээнүүд

### OpenAI-оор эхлэх хамгийн бага шаардлага

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Зөвхөн суурь хэрэгслүүдтэй локал Ollama

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### Бүх интерфэйс дээр вэб сервер

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

эсвэл

```
uagw --host 0.0.0.0
```

### A2A сервер localhost дээр өөрчлөн тохируулсан портоор

```
uaga --host 127.0.0.1 --port 8080
```

### Жижиг загварт зориулсан хэрэгслийг идэвхгүй болгох

```
uag --no-use-tool --tool-genre-mask 1
```

### Харилцан идэвхгүй файл боловсруулалт

```
uag --non-interactive README.md
```
