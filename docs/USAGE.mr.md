# वापर (कमांड-लाइन पर्याय)

हा दस्तऐवज uag एंट्री पॉइंटसाठी उपलब्ध कमांड-लाइन पर्यायांचे वर्णन करतो.

______________________________________________________________________

## एंट्री पॉइंट्स

| कमांड | पायथन मॉड्यूल | इंटरफेस |
|---|---|---|
| `uag` | `python -m uagent` | CLI (stdin लूप) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | वेब सर्व्हर (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | A2A HTTP server |

______________________________________________________________________

## CLI startup options (`uag`)

### `--workdir` / `-C <path>`

कार्य निर्देशिका. जर सेट न केल्यास, `UAGENT_WORKDIR` पर्यावरण चल (env var) वापरली जाते, नंतर वर्तमान निर्देशिका.
निर्देशिका अस्तित्वात नसल्यास ती तयार केली जाते.

### `--tool-genre-mask <int>`

टूल प्रकार बिटमास्क. जेव्हा दिले जाते, तेव्हा इंटरॅक्टिव्ह प्रकार निवडण्याचा प्रॉम्प्ट वगळला जातो.

| बिट | प्रकार | वर्णन |
|-----|-------|-------------|
| 1 | basic | आवश्यक फाइल/चॅट साधने |
| 2 | comm | संवाद साधने (Bluesky, Teams) |
| 4 | office | ऑफिस सूट साधने (Excel, PDF, PPTX) |
| 8 | devel | विकास साधने (git, lint, compile) |
| 16 | iot | IoT उपकरण साधने (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | कमांड अंमलबजावणी साधने |
| 64 | बाह्य | बाह्य प्लगइन साधने |
| 128 | मीडिया | प्रतिमा/ऑडिओ निर्मिती आणि विश्लेषण |
| 256 | फाइल | फाइल-व्यवस्थापन साधने |
| 512 | निर्देशांक | स्रोत/निर्देशांक नेव्हिगेशन साधने |
| 1024 | dev | विकासक आणि रिपॉझिटरी साधने |
| 2048 | web | वेब आणि ब्राउझर साधने |
| 4096 | utility | उपयुक्तता आणि समर्थन साधने |
| 8191 | all | सर्व साधने |

उदाहरणे:

```
uag --tool-genre-mask 1 # फक्त मूलभूत
uag --tool-genre-mask 9 # मूलभूत + विकास (1 + 8)
uag --tool-genre-mask 8191    # सर्व साधने
```

### `--use-tool` / `--no-use-tool`

LLM कडे टूल परिभाषा पाठवणे सक्षम किंवा अक्षम करा. `UAGENT_USE_TOOL` पर्यावरण चल बदलते.

- `--use-tool` साधन पाठवणे सुरू करते.
- `--no-use-tool` साधन पाठवणे बंद करते.

जेव्हा अक्षम केले जाते, तेव्हा LLM कडे कोणतीही टूल परिभाषा येत नाहीत आणि ते कोणतेही टूल कॉल करू शकत नाही.

### `--computer-use` / `--no-computer-use`

Computer Use सक्षम किंवा अक्षम करा. `UAGENT_COMPUTER_USE` पर्यावरण चल बदलते.

### `--inject-message` / `-M <message>`

सुरुवातीला LLM मध्ये संदेश इंजेक्ट करा आणि पूर्ण झाल्यानंतर बाहेर पडवा. याचा अर्थ `--non-interactive` असा होतो.

### `--embedded`

मर्यादित किंवा पुनरुत्पादन-संवेदनशील तैनातींसाठी एम्बेडेड मोड.

- सत्र स्टोअर अक्षम करते.
- स्पष्टपणे सक्षम न केल्यास `tool_catalog`, `tool_load`, `unload_tool` या टूल-व्यवस्थापन साधने लपवते.
- `--tool-genre-mask` दुर्लक्षित करते; स्पष्ट टूल लोड करण्यासाठी `--enable-tool` वापरा.

### `--enable-tool <name>`

स्टार्टअपवर एखादे टूल स्पष्टपणे लोड करा. हा पर्याय पुन्हा वापरता येतो, आणि अल्पविराम-विभक्त नावे देखील स्वीकारली जातात.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

निर्दिष्ट केलेली क्रमवारी जपली जाते आणि ती LLM कडे सादर केलेल्या साधन क्रमात प्रतिबिंबित होते. स्पष्टपणे सक्षम केलेल्या साधनांना स्वयंचलित अनलोडिंगपासून स्थिर केले जाते.

### `--plugin-dir <path>`

निर्दिष्ट केलेल्या निर्देशिकेतून प्लगइन्स लोड करा. हा पर्याय पुन्हा वापरता येऊ शकतो.

## CLI-फक्त पर्याय

### `--inject-message-auto <goal-options>`

गैर-परस्परसंवादी इंजेक्ट केलेल्या गोलापासून ऑटो-पायलट सुरू करा. मूल्य `:auto` प्रमाणेच पर्याय वापरते; जेव्हा त्यात पर्याय असतात तेव्हा संपूर्ण मूल्य उद्धृत करा.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --infinite"
```

सामान्य मोड समीक्षकाच्या निर्णय मार्गाचा वापर करतो. एकल-LLM सेंटिनल मोडमध्ये सामील होण्यासाठी `UAGENT_AUTO_SENTINEL=1` सेट करा. त्या मोडमध्ये, लक्ष्य LLM ने प्रत्येक प्रतिसाद नेमका खालीलपैकी एका मार्करने संपवणे आवश्यक आहे:

- `<AUTO_CONTINUE>` — आणखी एक फेरी चालवा
- `<AUTO_COMPLETE>` — यशस्वीरित्या समाप्त करा

गहाळ किंवा अमान्य मार्कर्स ऑटो-पायलट सुरक्षितपणे थांबवतात. हे तरीही लक्ष्य LLM चालवते; ते फक्त अतिरिक्त समीक्षक LLM कॉल टाळते.

### `--non-interactive`

गैर-संवादात्मक मोड. stdin लूप सुरू करत नाही. जर स्थितीय आर्गुमेंट म्हणून फाईल पथ दिला गेला, तर तो प्रक्रिया होतो आणि प्रोग्राम ताबडतोब बाहेर पडतो.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## वेब सर्व्हर पर्याय (`uagw`)

### `--host <address>`

वेब सर्व्हरसाठी बाइंड पत्ता (डीफॉल्ट: `127.0.0.1`, `UAGENT_WEB_HOST` द्वारे ओव्हरराइड करता येईल).

डीफॉल्टनुसार, वेब सर्व्हर फक्त localhost वर ऐकतो (`127.0.0.1`). नेटवर्कवरील इतर मशीनवरून प्रवेशयोग्य करण्यासाठी `--host 0.0.0.0` वापरा.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

वरील वर्णनात दिलेल्या बिटमास्कचा वापर करून टूल प्रकारांची निवड करा. निर्दिष्ट केल्यावर, इंटरॅक्टिव्ह प्रकारची प्रॉम्प्ट वगळली जाते.

### `--use-tool` / `--no-use-tool`

LLM कडे साधन परिभाषा पाठवणे सक्षम किंवा अक्षम करा. `UAGENT_USE_TOOL` ओव्हरराइड करते.

### `--computer-use` / `--no-computer-use`

Computer Use सक्षम किंवा अक्षम करा. `UAGENT_COMPUTER_USE` ओव्हरराइड करते.

### `--no-frontend`

HTML टेम्प्लेट्स किंवा स्थिर फ्रंटएंड फाइल्सशिवाय फक्त API चालवा.

### `--embedded`

सत्र स्टोअर अक्षम करा आणि साधन व्यवस्थापन साधने (`tool_catalog`, `tool_load`, `unload_tool`) लपवा.

## A2A सर्व्हर पर्याय (`uaga`)

### `--host <address>`

A2A HTTP सर्व्हरसाठी बाइंड पत्ता (डीफॉल्ट: `0.0.0.0`, `UAGENT_A2A_HOST` द्वारे ओव्हरराइड करता येईल).

### `--port <number>`

A2A HTTP सर्व्हरसाठी पोर्ट क्रमांक (डीफॉल्ट: `8765`, `UAGENT_A2A_PORT` द्वारे ओव्हररायड करता येण्याजोगे).

### `--reload`

कोड बदलांवर हॉट रीलोड सक्षम करा (डीफॉल्ट: बंद, `UAGENT_A2A_RELOAD` द्वारे ओव्हरराइड करता येईल).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

वरील वर्णन केलेल्या त्याच बिटमास्कचा वापर करून टूल प्रकारांची निवड करा. निर्दिष्ट केल्यास, इंटरॅक्टिव्ह प्रकार प्रॉम्प्ट वगळला जातो.

### `--use-tool` / `--no-use-tool`

LLM कडे साधन परिभाषा पाठवणे सक्षम किंवा अक्षम करा. `UAGENT_USE_TOOL` ओव्हरराइड करते.

### `--computer-use` / `--no-computer-use`

Computer Use सक्षम किंवा अक्षम करा.

### `--embedded`

सेशन स्टोअर अक्षम करा आणि टूल-व्यवस्थापन साधने (`tool_catalog`, `Computer Use`) लपवा.

`UAGENT_COMPUTER_USE` ओव्हरराइड करते.

### `--embedded`

सत्र स्टोअर अक्षम करा आणि टूल-व्यवस्थापन साधने (`tool_catalog`, `tool_load`, `unload_tool`) लपवा.

## संबंधित पर्यावरण चल | Variable | वर्णन |

|---|---|
| `UAGENT_PROVIDER` | LLM प्रदात्याचे नाव (प्रारंभी आवश्यक) |
| `UAGENT_*_API_KEY` | निवडलेल्या प्रदात्यासाठी API की |
| `UAGENT_WORKDIR` | डीफॉल्ट वर्किंग डिरेक्टरी |
| `UAGENT_WEB_HOST` | वेब सर्व्हर बाइंड पत्ता (डीफॉल्ट: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A सर्व्हर बाइंड पत्ता (डीफॉल्ट: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | A2A सर्व्हर पोर्ट (डीफॉल्ट: `8765`) |
| `UAGENT_A2A_RELOAD` | डीफॉल्टनुसार A2A हॉट रीलोड सक्षम करा |
| `UAGENT_USE_TOOL` | `0`, `false`, `no`, किंवा `off` सेट केल्यावर साधने अक्षम करा |
| `UAGENT_COMPUTER_USE` | डीफॉल्टनुसार Computer Use सक्षम किंवा अक्षम करा |
| `UAGENT_SESSION_STORE` | सत्र स्टोअर सक्षम किंवा अक्षम करा; एम्बेडेड मोड `0` ला भाग पाडतो |
| `UAGENT_PLUGIN_DIRS` | अतिरिक्त प्लगइन शोध निर्देशिका |
| `UAGENT_AUTO_SENTINEL` | `1` वर सेट केल्यावर एकल-LLM ऑटो-पायलट सेंटिनल मोडमध्ये सामील व्हा |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | सलग ताज्या टूल कॉलची कमाल संख्या (डीफॉल्ट: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | प्रत्येक वापरकर्ता ऑपरेशनसाठी कमाल LLM/टूल फेऱ्या (डीफॉल्ट: `200`) |
| `UAGENT_SHRINK_CNT` | संदेशांमध्ये ऐच्छिक ऑटो-श्रिंक मर्यादा (`0`/निर्धारित नाही = अक्षम) |
| `UAGENT_SHRINK_KEEP_LAST` | संकुचित केल्यानंतर जतन करायच्या संदेशांची संख्या (डीफॉल्ट: `20`) |
| `UAGENT_LANG` | इंटरफेस भाषा (`ja`, `en`, इत्यादी) |

सर्व पर्यावरण चलनांची संपूर्ण यादी पाहण्यासाठी [ENVIRONMENT.md](ENVIRONMENT.md) पहा.

## उदाहरणे

### OpenAI ने किमान प्रारंभ

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### फक्त मूलभूत साधनांसह स्थानिक ओल्लामा

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### सर्व इंटरफेसवर वेब सर्व्हर

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

किंवा

```
uagw --host 0.0.0.0
```

### A2A कस्टम पोर्टसह लोकलहोस्टवर सर्व्हर

```
uaga --host 127.0.0.1 --port 8080
```

### लहान मॉडेलसाठी साधने अक्षम करा

```
uag --no-use-tool --tool-genre-mask 1
```

### गैर-परस्परसंवादी फाइल प्रक्रिया

```
uag --non-interactive README.md
```
