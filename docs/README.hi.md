##उग क्यों?

**विक्रेता लॉक-इन से मुक्त हो जाएं।** अधिकांश एआई सहायक आपको एक विशिष्ट प्रदाता या क्लाउड सेवा से जोड़ते हैं। यूएजी अलग है.

- **आपकी मशीन पर स्थानीय रूप से चलता है**। आपका डेटा आपके पास रहता है (आपके द्वारा किए गए एपीआई कॉल को छोड़कर)।
- **प्रदाता स्वतंत्रता**: ओपनएआई, क्लाउड, जेमिनी, डीपसीक, ओलामा, एज़्योर, बेडरॉक, हगिंगफेस... 24 प्रदाता, सभी एक ही इंटरफ़ेस से पहुंच योग्य हैं। पर्यावरण चर को पुन: कॉन्फ़िगर करके उनके बीच स्वैप करें - कोई पुनर्स्थापना नहीं, कोई माइग्रेशन नहीं।
- **229 उपकरण**: फ़ाइल I/O, वेब खोज, छवि निर्माण, जीमेल, BLE डिवाइस स्कैनिंग, MCP सर्वर एकीकरण - **130 समानांतर-सुरक्षित हैं** (8 तक थ्रेड पूल के माध्यम से समवर्ती रूप से निष्पादित, `UAGENT_PARALLEL_WORKERS` के माध्यम से कॉन्फ़िगर करने योग्य)। जब एलएलएम एक साथ कई टूल कॉल सक्रिय करता है, तो यूएजी स्वचालित रूप से उन्हें समानांतर कर देता है।
- **3 यूआई + ए2ए**: सीएलआई, जीयूआई, वेब और एजेंट-टू-एजेंट प्रोटोकॉल। वही इंजन, कोई इंटरफ़ेस।
- **आईओटी तैयार**: स्विचबॉट, इकोनेट लाइट, मैटर, यूपीएनपी - एआई के माध्यम से अपने घरेलू उपकरणों को नियंत्रित करें।
- **एजेंट कौशल**: बाज़ार से समुदाय-निर्मित कौशल स्थापित करें। यूएजी को अंतहीन रूप से बढ़ाएँ।

यूएजी **आपकी शर्तों पर आपका एआई सहायक** है। किसी प्रदाता से बंधा नहीं, किसी इंटरफ़ेस से बंधा नहीं, किसी प्लेटफ़ॉर्म से बंधा नहीं।

### ⚡ समानांतर उपकरण निष्पादन

जब एलएलएम एक साथ कई टूल का अनुरोध करता है, तो यूएजी **स्वचालित रूप से उन्हें समानांतर** कर देता है।
130 उपकरण `x_parallel_safe` के रूप में चिह्नित हैं और `ThreadPoolExecutor` के माध्यम से समवर्ती रूप से निष्पादित होते हैं (डिफ़ॉल्ट रूप से 8 थ्रेड; बदलने के लिए `UAGENT_PARALLEL_WORKERS` सेट करें)।

**उदाहरण**: पूछें "नॉर्डिक राजधानियों में मौसम की जाँच करें" → एलएलएम ने `search_web` × 5 देशों को सक्रिय किया → सभी 5 खोजें समानांतर में चलती हैं → परिणाम एक बैच में एकत्र किए गए।

केवल पढ़ने योग्य उपकरण (फ़ाइल खोज, हैश गणना, निर्देशिका सूची, अनुवाद, डीबी क्वेरीज़, आदि) आक्रामक रूप से समानांतर हैं।

### 🧩 प्लगइन सिस्टम (Claude Code संगत)

uagent एक Claude Code-संगत प्लगइन सिस्टम लागू करता है। प्लगइन्स कौशल, एजेंट, MCP सर्वर, हुक और बहुत कुछ को `.claude-plugin/plugin.json` मेनिफेस्ट के साथ स्व-निहित निर्देशिकाओं में बंडल करते हैं।

**समर्थित घटक: कौशल, उप-एजेंट, MCP सर्वर, हुक (12 जीवनचक्र घटनाएँ), स्लैश कमांड, आउटपुट शैलियाँ, userConfig, निर्भरताएँ, चैनल, मार्केटप्लेस**

**CLI commands**:

```
:plugin list                         # स्थापित प्लगइन्स की सूची बनाएं
:plugin install <source> [--scope]
:plugin install <name>@<marketplace>  # बाज़ार से इंस्टॉल करें
:plugin remove <name>                # अनइंस्टॉल करें
:plugin enable/disable <name>        # टॉगल करें
:plugin marketplace add/remove/list  # बाज़ारों का प्रबंधन करें
:plugin init <name>                  # नया प्लगइन ढाँचा बनाएँ
```

विवरण के लिए पूरा दस्तावेज़ देखें। [DEVELOP_PLUGIN.md](../src/uagent/docs/DEVELOP_PLUGIN.md)

### 🤖 ऑटो-पायलट (`:ऑटो`)

यूएजी **कई एलएलएम राउंड में स्वायत्त रूप से एक लक्ष्य का पीछा कर सकता है**। जटिल, बहु-चरणीय कार्यों के लिए बिल्कुल सही, जिन्हें पुनरावृत्तीय परिशोधन की आवश्यकता होती है।

- **यह कैसे काम करता है**: प्रत्येक राउंड में एक मुख्य प्रश्न (चरण ए) होता है जिसके बाद एक समीक्षक निर्णय (चरण बी) होता है जो निर्णय लेता है "पूरा करें या जारी रखें?"
- **समान प्रदाता, समान एपीआई**: समीक्षक का निर्णय मुख्य क्वेरी के रूप में समान कोड पथ का उपयोग करता है - जिसमें प्रतिक्रिया एपीआई समर्थन भी शामिल है।
- **अलग न्यायाधीश एलएलएम** (वैकल्पिक): समीक्षक के लिए एक अलग प्रदाता/मॉडल का उपयोग करने के लिए `UAGENT_AP_PROVIDER` सेट करें (उदाहरण के लिए निर्णय लेने के लिए एक सस्ता मॉडल का उपयोग करें)।
- **कभी भी बाहर निकलें**: तुरंत रुकने के लिए `x` कुंजी दबाएँ, यहाँ तक कि प्रतिक्रिया के बीच में भी। या फिर समीक्षक को यह तय करने दें कि लक्ष्य कब पूरा होगा।
- **कॉन्फ़िगर करने योग्य**: बजट को नियंत्रित करने के लिए `--मैक्स-राउंड एन`।

संपूर्ण दस्तावेज़ीकरण के लिए [README_AUTO.md](README_AUTO.md) देखें।

### 🧩बैच स्टेट मैनेजर

यूएजी लंबे समय से चल रहे बहु-फ़ाइल कार्यों में प्रगति को ट्रैक कर सकता है। जब एलएलएम दर्जनों फ़ाइलों को संसाधित करता है, तो `बैच_स्टेट` डिस्क पर लंबित, पूर्ण और विफल फ़ाइलों की सूची को बनाए रखता है। यदि सत्र समाप्त हो जाता है या एक राउंड समाप्त हो जाता है, तो अगला रन वहीं से शुरू होता है जहां वह रुका था - कुछ भी नहीं खोता है।

### 🛡 मानव-इन-द-लूप

`ह्यूमन_आस्क` एलएलएम को रुकने देता है और विनाशकारी ऑपरेशन (फ़ाइल हटाना, ओवरराइट करना, शेल कमांड) करने से पहले आपकी पुष्टि मांगता है। आप नियंत्रण में रहें.

### 🛑 व्यवधान (सी-कुंजी/स्टॉप बटन)

किसी भी समय एलएलएम प्रतिक्रिया पीढ़ी को रोकें और एलएलएम में वापस स्टॉप कमांड इंजेक्ट करें।

| इंटरफ़ेस | कैसे टोकें |
|---|---|
| **सीएलआई** | एलएलएम स्ट्रीमिंग के दौरान `सी` कुंजी दबाएं - वर्तमान प्रतिक्रिया बंद हो जाती है, और \`\`स्टॉप'' को उपयोगकर्ता संदेश के रूप में भेजा जाता है ताकि एलएलएम तदनुसार प्रतिक्रिया दे सके |
| **वेब यूआई** | लाल **■ स्टॉप** बटन पर क्लिक करें (एलएलएम प्रसंस्करण के दौरान स्वचालित रूप से प्रकट होता है) |
| **डेस्कटॉप जीयूआई** | लाल **■** बटन पर क्लिक करें (एलएलएम प्रसंस्करण के दौरान स्वचालित रूप से प्रकट होता है) |

व्यवधान "प्रॉम्प्ट इंजेक्शन" के रूप में काम करता है: केवल निरस्त करने के बजाय, यह उपयोगकर्ता संदेश के रूप में एलएलएम में `"स्टॉप"` को वापस फीड करता है, जिससे वह व्यवधान को शालीनता से समाप्त करने या स्वीकार करने की अनुमति देता है।

ऑटो-पायलट मोड से बाहर निकलने के लिए `x` कुंजी दबाएँ (देखें [README_AUTO.md](README_AUTO.md))।

### 🕵️ ब्राउज़र ऑटोमेशन और वेब इंस्पेक्टर

दो पूरक नाटककार-आधारित उपकरण:

- **ब्राउज़र_प्लेराइट**: वास्तविक ब्राउज़र सत्र स्वचालित करें - नेविगेट करें, क्लिक करें, फ़ॉर्म भरें, डेटा निकालें, बहु-पृष्ठ प्रवाह को संभालें। बिना सिर या नेतृत्व के काम करता है।
- **नाटककार_इंस्पेक्टर**: ब्राउज़र बदलाव रिकॉर्ड करें, प्रत्येक चरण पर DOM स्नैपशॉट और स्क्रीनशॉट कैप्चर करें। वेब इंटरैक्शन को डीबग करने या समय के साथ पृष्ठ परिवर्तनों का ऑडिट करने के लिए उपयोगी।

## Realtime वॉयस मोड फुल-डुप्लेक्स माइक्रोफोन और स्पीकर इनपुट/आउटपुट को सपोर्ट करता है। यदि AEC3 बैकएंड गायब है, तो uag स्वचालित रूप से pywebrtc-audio इंस्टॉल कर देता है।

**रीयलटाइम प्रदाता**: OpenAI Realtime, Azure OpenAI GPT Realtime, Google Gemini Live, xAI Grok Voice और Amazon Bedrock Nova Sonic। Bedrock द्विदिश-स्ट्रीमिंग SDK स्वचालित रूप से तभी स्थापित होता है जब Bedrock का चयन किया जाता है।

```bat
python scheck.py realtime
```

AEC3 वास्तविक माइक्रोफ़ोन सिग्नल (निकट) और वास्तव में स्पीकर (दूर) पर भेजे गए ऑडियो का उपयोग करता है। ऑडियो समस्याओं की जांच करते समय ही डायग्नोस्टिक्स सक्षम करें।

```bat
set UAGENT_REALTIME_AUDIO_DEBUG=1
python scheck.py realtime
```

### OpenAI Realtime Function Calling

OpenAI Realtime सुरक्षा-सीमित Function Calling एकीकरण का समर्थन करता है। वर्तमान एडाप्टर स्वचालित रूप से रीड-ओनली get_current_time फ़ंक्शन को उजागर करता है। विनाशकारी उपकरण और उपकरण नियंत्रण के लिए एक स्पष्ट अनुमति सूची और पुष्टिकरण प्रवाह की आवश्यकता होती है। Grok रीयलटाइम एक अलग एडाप्टर का उपयोग करता है और इस OpenAI-विशिष्ट Function Calling पथ का उपयोग नहीं करता है।
