# XLSM静的解析

`xlsm_analyze` は、Excelマクロ有効ブック（`.xlsm`）を読み取り専用で調査するツールです。Excelを起動したりマクロを実行したりせずに、ブック構造と埋め込みVBAソースを抽出します。

## なぜ有用か

重要な業務ロジックは、ワークシート、数式、イベント処理、VBAモジュールに分散していることがあります。`xlsm_analyze`は、それらを追跡可能なレポートにまとめ、システム刷新、移行、監査、Webシステム化の検討前にレビューできるようにします。

## 解析対象

### ブック構造

- ワークシート名とサイズ
- 非空セル数
- 数式とセル番地
- 結合範囲
- 基盤ライブラリから取得できるブックリンク

### VBA

- 埋め込みVBAモジュールとソースコード
- `Sub`、`Function`、`Property`プロシージャ
- プロシージャの行番号
- `Call`および呼び出し可能な名前の参照
- モジュール単位の呼び出し情報
- 次のような注意が必要な処理の検出
  - `Shell`によるコマンド実行
  - ファイルの作成、削除、コピー、ディレクトリ参照
  - HTTPなどのネットワークアクセス
  - 外部ブックのオープンやリンク更新
  - データベースアクセス

## 出力形式

- **JSON**：後続ツールや自動レビュー向け
- **Markdown**：人が読むレポートやドキュメント向け

抽出したVBAソースを含めず、メタデータと検出結果だけにしたい場合は、`include_source=false`を指定します。

## 使用例

```text
xlsm_analyze(
  input_path="finance_model.xlsm",
  output_path="finance_model_analysis.md",
  output_format="markdown",
  include_source=true
)
```

## 暗号化ファイル

パスワード保護されたOfficeファイルは、変換ツールまたは解析ツールに `password` を指定して処理できます。`msoffcrypto-tool` が未導入の場合は自動インストールします。復号データは解析中だけ一時ファイルに保存し、完了後に削除します。VBAプロジェクト自体の保護や未対応の暗号方式では、ソースを抽出できない場合があります。

## 安全性と対応OS

- VBAは静的に抽出・解析され、実行されません。
- `oletools`は埋め込みの`vbaProject.bin`を直接読み取るため、Microsoft Excelは不要です。
- ワークシートの調査には`openpyxl`を使用します。
- 解析処理はWindows、macOS、Linuxでの動作を想定しています。
- パスワード保護、破損、難読化、または未対応のブックでは、警告や不完全な結果が出る場合があります。

## 対象範囲と制限

このツールはブック内で確認できた証拠を報告するもので、プログラムの動作を完全に証明するものではありません。動的に生成されるVBA、強く難読化されたコード、ExcelのCOMや実行環境に依存する処理は、追加の手動レビューが必要になる場合があります。結果は監査・発見の補助資料として利用し、セキュリティレビューや業務担当者による確認の代替にはしないでください。
