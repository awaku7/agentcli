# نحوه استفاده (گزینه‌های خط فرمان)

این سند گزینه‌های خط فرمان موجود برای نقاط ورود uag را توصیف می‌کند.

______________________________________________________________________

## نقاط ورود

| فرمان | ماژول پایتون | رابط |
|---|---|---|
| `uag` | `python -m uagent` | CLI (حلقه stdin) |
| `uagg` | `python -m uagent.gui` | رابط کاربری گرافیکی (tkinter) |
| `uagw` | `python -m uagent.web` | سرور وب (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | سرور A2A HTTP |

## گزینه‌های راه‌اندازی CLI (`uag`)

### `--workdir` / `-C <path>`

دایرکتوری کاری. اگر تنظیم نشود، به متغیر محیطی `UAGENT_WORKDIR` و سپس به دایرکتوری فعلی بازمی‌گردد.
اگر دایرکتوری وجود نداشته باشد، ایجاد می‌شود.

### `--tool-genre-mask <int>`

ماسک بیت ژانر ابزار. در صورت ارائه، پرس‌وجوی تعاملی انتخاب ژانر نادیده گرفته می‌شود.

| بیت | ژانر | توضیحات |
|-----|-------|-------------|
| 1 | basic | ابزارهای ضروری فایل/چت |
| 2 | comm | ابزارهای ارتباطی (Bluesky, Teams) |
| 4 | office | ابزارهای مجموعه اداری (Excel, PDF, PPTX) |
| 8 | توسعه | ابزارهای توسعه (گیت، لینت، کامپایل) |
| 16 | iot | ابزارهای دستگاه IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | ابزارهای اجرای فرمان |
| 64 | external | ابزارهای افزونهٔ خارجی |
| 128 | media | تولید و تحلیل تصویر/صدا |
| 256 | file | ابزارهای مدیریت فایل |
| 512 | index | ابزارهای پیمایش سورس/شاخص |
| 1024 | dev | ابزارهای توسعه‌دهنده و مخزن |
| 2048 | web | ابزارهای وب و مرورگر |
| 4096 | ابزار کمکی | ابزارهای کمکی و پشتیبانی |
| 8191 | همه | همه ابزارها |

مثال‌ها:

```
uag --tool-genre-mask 1 # فقط پایه‌ای
uag --tool-genre-mask 9 # پایه‌ای + توسعه (1 + 8)
uag --tool-genre-mask 8191    # تمام ابزارها
```

### `--use-tool` / `--no-use-tool`

ارسال تعاریف ابزار به LLM را فعال یا غیرفعال می‌کند. متغیر محیطی `UAGENT_USE_TOOL` را بازنویسی می‌کند.

- `--use-tool` ارسال ابزار را اجباری می‌کند.
- `--no-use-tool` ارسال ابزار را غیرفعال می‌کند.

وقتی غیرفعال باشد، LLM هیچ تعریف ابزاری دریافت نمی‌کند و نمی‌تواند هیچ ابزاری را فراخوانی کند.

### `--computer-use` / `--no-computer-use`

استفاده از کامپیوتر را فعال یا غیرفعال می‌کند. بر متغیر محیطی `UAGENT_COMPUTER_USE` اولویت دارد.

### `--inject-message` / `-M <message>`

در هنگام راه‌اندازی، پیامی را به LLM تزریق می‌کند و پس از اتمام خروجی می‌دهد. این به معنای `--non-interactive` است.

### `--embedded`

حالت تعبیه‌شده برای استقرارهای محدود یا حساس به قابلیت بازتولید.

- مخزن جلسه را غیرفعال می‌کند.
- ابزارهای مدیریت ابزار (`tool_catalog`، `tool_load`، `unload_tool`) را مخفی می‌کند مگر اینکه صراحتاً فعال شده باشند.
- `--tool-genre-mask` را نادیده می‌گیرد؛ برای بارگذاری صریح ابزار از `--enable-tool` استفاده کنید.

### `--enable-tool <name>`

بارگذاری صریح یک ابزار در زمان راه‌اندازی. این گزینه می‌تواند تکرار شود و نام‌های جداشده با ویرگول نیز پذیرفته می‌شوند.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

ترتیب مشخص‌شده حفظ می‌شود و در ترتیب ابزارهای ارائه‌شده به LLM منعکس می‌شود. ابزارهای صریحاً فعال‌شده در برابر بارگذاری خودکار محافظت می‌شوند.

### `--plugin-dir <path>`

پلاگین‌ها را از دایرکتوری مشخص‌شده بارگذاری می‌کند. این گزینه می‌تواند تکرار شود.

## گزینه‌های فقط CLI

### `--inject-message-auto <goal-options>`

شروع خودکار (auto-pilot) از یک هدف تزریق‌شده غیرتعاملی. این مقدار از همان گزینه‌های `:auto` استفاده می‌کند؛ هنگامی که شامل گزینه‌ها است، مقدار کامل را با علامت نقل قول بنویسید.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --infinite"
```

حالت عادی از مسیر قضاوت بازبین استفاده می‌کند. برای استفاده از حالت سِنتینل تک LLM، مقدار `UAGENT_AUTO_SENTINEL=1` را تنظیم کنید. در این حالت، هدف LLM باید هر پاسخ را دقیقاً با یکی از موارد زیر پایان دهد:

- `<AUTO_CONTINUE>` — اجرای دور دیگر
- `<AUTO_COMPLETE>` — پایان موفقیت‌آمیز

نبود یا نامعتبر بودن نشانگرها، حالت خلبان خودکار را به‌طور ایمن متوقف می‌کند. این همچنان هدف LLM را اجرا می‌کند؛ این تنها از تماس اضافی با بازبین LLM جلوگیری می‌کند.

### `--non-interactive`

حالت غیرتعاملی. حلقه stdin را شروع نمی‌کند. اگر یک مسیر فایل به‌عنوان آرگومان موقعیتی داده شود، پردازش شده و برنامه بلافاصله خروجی می‌گیرد.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## گزینه‌های سرور وب (`uagw`)

### `--host <address>`

آدرس اتصال برای وب‌سرور (پیش‌فرض: `127.0.0.1`، قابل تغییر توسط `UAGENT_WEB_HOST`).

به طور پیش‌فرض، وب‌سرور فقط روی localhost (`127.0.0.1`) گوش می‌دهد. برای دسترسی از سایر دستگاه‌های شبکه، از `--host 0.0.0.0` استفاده کنید.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

انتخاب ژانرهای ابزار با استفاده از همان ماسک بیتی که در بالا توضیح داده شد. وقتی مشخص شود، پرس‌وجوی تعاملی ژانر نادیده گرفته می‌شود.

### `--use-tool` / `--no-use-tool`

ارسال تعاریف ابزار به LLM را فعال یا غیرفعال کنید. `UAGENT_USE_TOOL` را override می‌کند.

### `--computer-use` / `--no-computer-use`

استفاده از کامپیوتر را فعال یا غیرفعال می‌کند. `UAGENT_COMPUTER_USE` را بازنویسی می‌کند.

### `--no-frontend`

اجرای API-only بدون قالب‌های HTML یا فایل‌های فرانت‌اند ایستا.

### `--embedded`

ذخیره‌سازی جلسه را غیرفعال کرده و ابزارهای مدیریت ابزار (`tool_catalog`، `tool_load`، `unload_tool`) را پنهان می‌کند.

## گزینه‌های سرور A2A (`uaga`)

### `--host <address>`

آدرس اتصال برای سرور A2A HTTP (پیش‌فرض: `0.0.0.0`، قابل تغییر با `UAGENT_A2A_HOST`).

### `--port <number>`

شماره پورت برای سرور A2A HTTP (پیش‌فرض: `8765`، قابل تغییر توسط `UAGENT_A2A_PORT`).

### `--reload`

فعال‌سازی بارگذاری مجدد داغ در هنگام تغییرات کد (پیش‌فرض: غیرفعال، قابل تغییر توسط `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

انتخاب ژانرهای ابزار با استفاده از ماسک بیتی توصیف‌شده در بالا. وقتی مشخص شود، پرس‌وجوی تعاملی ژانر نادیده گرفته می‌شود.

### `--use-tool` / `--no-use-tool`

ارسال تعاریف ابزار به LLM را فعال یا غیرفعال کنید. مقید `UAGENT_USE_TOOL` را نادیده می‌گیرد.

### `--computer-use` / `--no-computer-use`

استفاده از رایانه را فعال یا غیرفعال می‌کند. `UAGENT_COMPUTER_USE` را بازنویسی می‌کند.

### `--embedded`

ذخیره‌سازی جلسه را غیرفعال کرده و ابزارهای مدیریت ابزار (`tool_catalog`، `tool_load`، `unload_tool`) را پنهان می‌کند.

## متغیرهای محیطی مرتبط

| متغیر | توضیحات |
|---|---|
| `UAGENT_PROVIDER` | نام ارائه‌دهنده (در شروع به کار الزامی است) |
| `UAGENT_*_API_KEY` | کلید API برای ارائه‌دهندهٔ انتخابی |
| `UAGENT_WORKDIR` | دایرکتوری کاری پیش‌فرض |
| `UAGENT_WEB_HOST` | آدرس اتصال سرور وب (پیش‌فرض: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A آدرس اتصال سرور (پیش‌فرض: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | پورت سرور A2A (پیش‌فرض: `8765`) |
| `UAGENT_A2A_RELOAD` | فعال‌سازی بارگذاری مجدد داغ A2A به‌صورت پیش‌فرض |
| `UAGENT_USE_TOOL` | هنگام تنظیم روی `0`، `false`، `no` یا `off`، ابزارها را غیرفعال می‌کند |
| `UAGENT_COMPUTER_USE` | استفاده از رایانه را به‌طور پیش‌فرض فعال یا غیرفعال می‌کند |
| `UAGENT_SESSION_STORE` | فعال یا غیرفعال کردن ذخیره‌سازی جلسه؛ حالت تعبیه‌ای مقدار را روی `0` قرار می‌دهد |
| `UAGENT_PLUGIN_DIRS` | مسیرهای جستجوی افزونه اضافی |
| `UAGENT_AUTO_SENTINEL` | با تنظیم روی `1`، در حالت تک-LLM خلبان خودکار نگهبان شرکت کنید |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | حداکثر فراخوانی‌های متوالی ابزار جدید (پیش‌فرض: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | حداکثر دورهای LLM/ابزار در هر عملیات کاربر (پیش‌فرض: `200`) |
| `UAGENT_SHRINK_CNT` | آستانه اختیاری خود-تراکم در پیام‌ها (`0`/تنظیم‌نشده = غیرفعال) |
| `UAGENT_SHRINK_KEEP_LAST` | پیام‌های قابل نگهداری پس از تراکم (پیش‌فرض: `20`) |
| `UAGENT_LANG` | زبان رابط کاربری (`ja`، `en` و غیره) |

برای مشاهده فهرست کامل متغیرهای محیطی، به [ENVIRONMENT.md](ENVIRONMENT.md) مراجعه کنید.

## مثال‌ها

### حداقل شروع با OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### محلی Ollama فقط با ابزارهای پایه

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### سرور وب روی تمام رابط‌ها

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

یا

```
uagw --host 0.0.0.0
```

### A2A سرور روی localhost با پورت سفارشی

```
uaga --host 127.0.0.1 --port 8080
```

### غیرفعال کردن ابزارها برای یک مدل کوچک

```
uag --no-use-tool --tool-genre-mask 1
```

### پردازش غیرتعاملی فایل

```
uag --non-interactive README.md
```
