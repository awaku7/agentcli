# שימוש (אפשרויות שורת הפקודה)

מסמך זה מתאר את אפשרויות שורת הפקודה הזמינות עבור נקודות הכניסה של uag.

______________________________________________________________________

## נקודות כניסה

| פקודה | מודול Python | ממשק |
|---|---|---|
| `uag` | `python -m uagent` | CLI (לולאת stdin) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | שרת אינטרנט (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | שרת A2A HTTP |

______________________________________________________________________

## אפשרויות הפעלה של CLI (`uag`)

### `--workdir` / `-C <path>`

ספריית עבודה. אם לא מוגדר, נעשה שימוש במשתנה הסביבה `UAGENT_WORKDIR`, ולאחר מכן בספרייה הנוכחית.
הספרייה תיווצר אם היא אינה קיימת.

### `--tool-genre-mask <int>`

מסכת סיביות של ז'אנר הכלים. כאשר מוגדר, דילוג על השאילתה האינטראקטיבית לבחירת ז'אנר.

| סיבית | ז'אנר | תיאור |
|-----|-------|-------------|
| 1 | basic | כלי קבצים/צ'אט חיוניים |
| 2 | comm | כלי תקשורת (Bluesky, Teams) |
| 4 | office | כלי חבילת Office (Excel, PDF, PPTX) |
| 8 | devel | כלי פיתוח (git, lint, compile) |
| 16 | iot | כלי מכשירי IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | כלי ביצוע פקודות |
| 64 | external | כלי תוספים חיצוניים |
| 128 | media | יצירת וניתוח תמונות/אודיו |
| 256 | file | כלי ניהול קבצים |
| 512 | index | כלי ניווט בקוד מקור/אינדקס |
| 1024 | dev | כלי מפתחים ומאגרים |
| 2048 | web | כלי אינטרנט ודפדפן |
| 4096 | utility | כלי עזר ותמיכה |
| 8191 | all | כל הכלים |

דוגמאות:

```
uag --tool-genre-mask 1 # בסיסי בלבד
uag --tool-genre-mask 9 # בסיסי + פיתוח (1 + 8)
uag --tool-genre-mask 8191    # כל הכלים
```

### `--use-tool` / `--no-use-tool`

הפעלה או השבתה של שליחת הגדרות כלים ל-LLM. עוקף את משתנה הסביבה `UAGENT_USE_TOOL`.

- `--use-tool` מאלץ את שליחת הכלים.
- `--no-use-tool` מאלץ את כיבוי שליחת הכלים.

כאשר האפשרות מושבתת, ה-LLM אינו מקבל הגדרות כלים ואינו יכול לקרוא לשום כלי.

### `--computer-use` / `--no-computer-use`

הפעלה או השבתה של "שימוש במחשב". עוקף את משתנה הסביבה `UAGENT_COMPUTER_USE`.

### `--inject-message` / `-M <message>`

מזריק הודעה ל-LLM בעת ההפעלה ויוצא לאחר השלמת התהליך. פעולה זו מרמזת על `--non-interactive`.

### `--embedded`

מצב מוטמע לפריסות מוגבלות או רגישות לשחזור.

- מבטל את מאגר ההפעלות.
- מסתיר את כלי ניהול הכלים (`tool_catalog`, `tool_load`, `unload_tool`) אלא אם הופעלו במפורש.
- מתעלם מ-`--tool-genre-mask`; השתמש ב-`--enable-tool` לטעינת כלים במפורש.

### `--enable-tool <name>`

טעינה מפורשת של כלי בעת ההפעלה. ניתן לחזור על האפשרות, וניתן גם להזין שמות מופרדים בפסיקים.

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

הסדר שצוין נשמר ומשתקף בסדר הכלים המוצג ל-LLM. כלים שהופעלו במפורש מוגנים מפני פריקה אוטומטית.

### `--plugin-dir <path>`

טען תוספים מהספרייה שצוינה. ניתן לחזור על האפשרות.

## אפשרויות ל-CLI בלבד

### `--inject-message-auto <goal-options>`

הפעל את ה-Auto-Pilot מתוך מטרה שהוזרקה שאינה אינטראקטיבית. הערך משתמש באותן אפשרויות כמו `:auto`; יש לצטט את הערך המלא כאשר הוא מכיל אפשרויות.

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "מיין את הפריטים --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "מיין את הפריטים --infinite"
```

המצב הרגיל משתמש במסלול שיקול הדעת של הבודק. הגדר `UAGENT_AUTO_SENTINEL=1` כדי לעבור למצב שומר יחיד-LLM. במצב זה, היעד LLM חייב לסיים כל תגובה באחד מהסימונים הבאים בדיוק:

- `<AUTO_CONTINUE>` — להריץ סיבוב נוסף
- `<AUTO_COMPLETE>` — לסיים בהצלחה

סימונים חסרים או לא חוקיים עוצרים את הטייס האוטומטי בבטחה. ה-LLM היעד עדיין פועל; האפשרות רק נמנעת מהשיחה הנוספת ל-LLM של הבודק.

### `--non-interactive`

מצב לא-אינטראקטיבי. אינו מפעיל את לולאת ה-stdin. אם נמסר נתיב קובץ כארגומנט מיקומי, הוא מעובד והתוכנית מסתיימת מיד.

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## אפשרויות שרת האינטרנט (`uagw`)

### `--host <address>`

כתובת הקישור של שרת האינטרנט (ברירת מחדל: `127.0.0.1`, ניתנת לשינוי באמצעות `UAGENT_WEB_HOST`).

כברירת מחדל, שרת האינטרנט מאזין רק ל-localhost (`127.0.0.1`). כדי לאפשר גישה אליו ממחשבים אחרים ברשת, השתמש ב-`--host 0.0.0.0`.

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

בחרו ז'אנרים של כלים באמצעות אותה מסכת סיביות שתוארה לעיל. כאשר מצוין, ההנחיה האינטראקטיבית לגבי הז'אנר מדלגת.

### `--use-tool` / `--no-use-tool`

הפעל או השבת שליחת הגדרות כלים ל-LLM. עוקף את `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

הפעל או השבת את השימוש במחשב. עוקפת את `UAGENT_COMPUTER_USE`.

### `--no-frontend`

הפעלת API בלבד ללא תבניות HTML או קבצי ממשק סטטיים.

### `--embedded`

משבית את מאגר ההפעלות ומסתיר את כלי ניהול הכלים (`tool_catalog`, `tool_load`, `unload_tool`).

## אפשרויות שרת A2A (`uaga`)

### `--host <address>`

כתובת קישור עבור שרת A2A HTTP (ברירת מחדל: `0.0.0.0`, ניתנת לעקיפה באמצעות `UAGENT_A2A_HOST`).

### `--port <מספר>`

מספר היציאה של שרת A2A HTTP (ברירת מחדל: `8765`, ניתן לעקוף באמצעות `UAGENT_A2A_PORT`).

### `--reload`

הפעל טעינה חמה בעת שינויים בקוד (ברירת מחדל: כבוי, ניתן לעקוף באמצעות `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

בחירת ז'אנרים של כלים באמצעות מסיכת הסיביות שתוארה לעיל. כאשר מוגדר, השאילתה האינטראקטיבית לגבי הסוג מדלגת.

### `--use-tool` / `--no-use-tool`

הפעל או השבת שליחת הגדרות כלים ל-LLM. עוקף את `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

הפעלה או השבתה של "שימוש במחשב". עוקף את `UAGENT_COMPUTER_USE`.

### `--embedded`

משבית את מאגר ההפעלות ומסתיר את כלי ניהול הכלים (`tool_catalog`, `tool_load`, `unload_tool`).

## משתני סביבה קשורים

| משתנה | תיאור |
|---|---|
| `UAGENT_PROVIDER` | שם ספק LLM (נדרש בעת ההפעלה) |
| `UAGENT_*_API_KEY` | מפתח API עבור הספק הנבחר |
| `UAGENT_WORKDIR` | ספריית עבודה ברירת מחדל |
| `UAGENT_WEB_HOST` | כתובת קישור של שרת האינטרנט (ברירת מחדל: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | כתובת קישור של שרת A2A (ברירת מחדל: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | יציאת שרת A2A (ברירת מחדל: `8765`) |
| `UAGENT_A2A_RELOAD` | הפעל טעינה חמה של A2A כברירת מחדל |
| `UAGENT_USE_TOOL` | השבת כלים כאשר מוגדר ל-`0`, `false`, `no` או `off` |
| `UAGENT_COMPUTER_USE` | הפעל או השבת את 'שימוש במחשב' כברירת מחדל |
| `UAGENT_SESSION_STORE` | הפעל או השבת את מאגר ההפעלות; במצב מוטמע הערך הוא `0` |
| `UAGENT_PLUGIN_DIRS` | ספריות חיפוש תוספים נוספות |
| `UAGENT_AUTO_SENTINEL` | הצטרפות למצב השמירה האוטומטי של LLM יחיד כאשר מוגדר ל-`1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | מספר מקסימלי של קריאות כלים חדשות ברצף (ברירת מחדל: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | מספר מקסימלי של מחזורי LLM/כלי לכל פעולת משתמש (ברירת מחדל: `200`) |
| `UAGENT_SHRINK_CNT` | סף צמצום אוטומטי אופציונלי בהודעות (`0`/לא מוגדר = מושבת) |
| `UAGENT_SHRINK_KEEP_LAST` | מספר ההודעות שיש לשמור לאחר הצמצום (ברירת מחדל: `20`) |
| `UAGENT_LANG` | שפת הממשק (`ja`, `en`, וכו') |

לרשימה המלאה של משתני הסביבה, ראה [ENVIRONMENT.md](ENVIRONMENT.md).

## דוגמאות

### התחלה מינימלית עם OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Ollama מקומי עם כלים בסיסיים בלבד

```
הגדר UAGENT_PROVIDER=ollama
הגדר UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### שרת אינטרנט על כל הממשקים

```
הגדר UAGENT_WEB_HOST=0.0.0.0
uagw
```

או

```
uagw --host 0.0.0.0
```

### שרת A2A ב-localhost עם יציאה מותאמת אישית

```
uaga --host 127.0.0.1 --port 8080
```

### השבתת כלים עבור מודל קטן

```
uag --no-use-tool --tool-genre-mask 1
```

### עיבוד קבצים לא אינטראקטיבי

```
uag --non-interactive README.md
```
