# วิธีใช้ (ตัวเลือกบรรทัดคำสั่ง)

เอกสารนี้อธิบายตัวเลือกบรรทัดคำสั่งที่มีอยู่สำหรับจุดเข้า uag

______________________________________________________________________

## จุดเข้า

| คำสั่ง | โมดูล Python | อินเทอร์เฟซ |
|---|---|---|
| `uag` | `python -m uagent` | CLI (วงจร stdin) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | Web server (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | A2A HTTP server |

______________________________________________________________________

## ตัวเลือกการเริ่มต้น CLI (`uag`)

### `--workdir` / `-C <path>`

ไดเรกทอรีทำงาน หากไม่กำหนด จะใช้ตัวแปรสภาพแวดล้อม `UAGENT_WORKDIR` เป็นค่าเริ่มต้น แล้วจึงใช้ไดเรกทอรีปัจจุบัน
หากไดเรกทอรีดังกล่าวไม่มีอยู่ จะสร้างขึ้น

### `--tool-genre-mask <int>`

บิตมาสก์ประเภทเครื่องมือ เมื่อกำหนดค่านี้ ระบบจะข้ามขั้นตอนการเลือกประเภทเครื่องมือแบบโต้ตอบ

| บิต | ประเภท | คำอธิบาย |
|-----|-------|-------------|
| 1 | basic | เครื่องมือไฟล์/แชทพื้นฐาน |
| 2 | comm | เครื่องมือการสื่อสาร (Bluesky, Teams) |
| 4 | office | เครื่องมือชุดสำนักงาน (Excel, PDF, PPTX) |
| 8 | devel | เครื่องมือพัฒนา (git, lint, compile) |
| 16 | iot | เครื่องมืออุปกรณ์ IoT (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | เครื่องมือการสั่งคำสั่ง |
| 64 | external | เครื่องมือปลั๊กอินภายนอก |
| 128 | media | การสร้างและวิเคราะห์ภาพ/เสียง |
| 256 | file | เครื่องมือจัดการไฟล์ |
| 512 | index | เครื่องมือนำทางโค้ดต้นฉบับ/ดัชนี |
| 1024 | dev | เครื่องมือสำหรับนักพัฒนาและที่เก็บโค้ด |
| 2048 | web | เครื่องมือเว็บและเบราว์เซอร์ |
| 4096 | utility | เครื่องมืออรรถประโยชน์และสนับสนุน |
| 8191 | all | เครื่องมือทั้งหมด |

ตัวอย่าง:

```
uag --tool-genre-mask 1 # เฉพาะ basic
uag --tool-genre-mask 9 # basic + devel (1 + 8)
uag --tool-genre-mask 8191    # ทุกเครื่องมือ
```

### `--use-tool` / `--no-use-tool`

เปิดหรือปิดการส่งนิยามเครื่องมือไปยัง LLM. แทนที่ตัวแปรสภาพแวดล้อม `UAGENT_USE_TOOL`.

- `--use-tool` บังคับให้ส่งนิยามเครื่องมือเป็นเปิด
- `--no-use-tool` บังคับให้ส่งนิยามเครื่องมือเป็นปิด

เมื่อปิดใช้งาน LLM จะไม่รับนิยามเครื่องมือใด ๆ และไม่สามารถเรียกใช้เครื่องมือใดได้

### `--computer-use` / `--no-computer-use`

เปิดหรือปิดใช้งาน Computer Use แทนที่ตัวแปรสภาพแวดล้อม `UAGENT_COMPUTER_USE`

### `--inject-message` / `-M <message>`

แทรกข้อความเข้าไปใน LLM เมื่อเริ่มต้นและออกหลังจากเสร็จสิ้น สิ่งนี้หมายถึง `--non-interactive`

### `--embedded`

โหมดฝังตัวสำหรับการปรับใช้ที่มีข้อจำกัดหรือต้องการความซ้ำได้

- ปิดการใช้งานที่เก็บเซสชัน
- ซ่อนเครื่องมือจัดการเครื่องมือ (`tool_catalog`, `tool_load`, `unload_tool`) เว้นแต่จะเปิดใช้งานอย่างชัดเจน
- ไม่สนใจ `--tool-genre-mask`; ใช้ `--enable-tool` เพื่อโหลดเครื่องมืออย่างชัดเจน

### `--enable-tool <name>`

โหลดเครื่องมืออย่างชัดเจนเมื่อเริ่มต้นระบบ ตัวเลือกนี้สามารถใช้ซ้ำได้ และชื่อที่คั่นด้วยเครื่องหมายจุลภาคก็ได้รับการยอมรับเช่นกัน

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

ลำดับที่ระบุจะถูกรักษาไว้และสะท้อนในลำดับเครื่องมือที่ส่งไปยัง LLM เครื่องมือที่เปิดใช้งานอย่างชัดเจนจะถูกป้องกันไม่ให้ถูกถอนการติดตั้งโดยอัตโนมัติ

### `--plugin-dir <path>`

โหลดปลั๊กอินจากไดเรกทอรีที่ระบุ ตัวเลือกนี้สามารถใช้ซ้ำได้

## ตัวเลือกเฉพาะ CLI

### `--inject-message-auto <goal-options>`

เริ่มโหมดอัตโนมัติจากเป้าหมายที่ถูกฉีดแบบไม่โต้ตอบ ค่านี้ใช้ตัวเลือกเดียวกันกับ `:auto`; ให้ใส่เครื่องหมายคำพูดรอบค่าทั้งหมดเมื่อค่าดังกล่าวมีตัวเลือกอยู่

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "จัดเรียงรายการ --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "จัดเรียงรายการ --infinite"
```

โหมดปกติใช้เส้นทางตัดสินของผู้ตรวจสอบ ตั้งค่า `UAGENT_AUTO_SENTINEL=1` เพื่อเปิดใช้งานโหมด sentinel แบบ single-LLM ในโหมดนั้น LLM เป้าหมายต้องจบการตอบกลับแต่ละครั้งด้วยหนึ่งในสองตัวเลือกต่อไปนี้เท่านั้น:

- `<AUTO_CONTINUE>` — ดำเนินการรอบใหม่
- `<AUTO_COMPLETE>` — เสร็จสิ้นอย่างสำเร็จ

หากไม่มีเครื่องหมายหรือเครื่องหมายไม่ถูกต้อง ระบบจะหยุดโหมดอัตโนมัติอย่างปลอดภัย โหมดนี้ยังคงเรียกใช้ LLM เป้าหมายอยู่ แต่จะหลีกเลี่ยงการเรียก LLM ของผู้ตรวจสอบเพิ่มเติม

### `--non-interactive`

โหมดไม่โต้ตอบ (Non-interactive) ไม่เริ่มวงจร stdin หากระบุเส้นทางไฟล์เป็นอาร์กิวเมนต์ตำแหน่ง ระบบจะประมวลผลและโปรแกรมจะออกทันที

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## ตัวเลือกของเว็บเซิร์ฟเวอร์ (`uagw`)

### `--host <address>`

ที่อยู่การผูกมัดสำหรับเว็บเซิร์ฟเวอร์ (ค่าเริ่มต้น: `127.0.0.1`, สามารถเปลี่ยนได้ด้วย `UAGENT_WEB_HOST`).

ตามค่าเริ่มต้น เซิร์ฟเวอร์เว็บจะรับฟังการเชื่อมต่อเฉพาะบน localhost (`127.0.0.1`) เท่านั้น หากต้องการให้สามารถเข้าถึงได้จากเครื่องอื่นในเครือข่าย ให้ใช้ `--host 0.0.0.0`

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

เลือกประเภทเครื่องมือโดยใช้บิตมาสก์เดียวกันกับที่อธิบายไว้ข้างต้น เมื่อกำหนดไว้ หน้าจอถามประเภทเครื่องมือแบบโต้ตอบจะถูกข้ามไป

### `--use-tool` / `--no-use-tool`

เปิดหรือปิดการส่งคำนิยามเครื่องมือไปยัง LLM แทนที่ `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

เปิดหรือปิดการใช้งาน Computer Use. แทนที่ `UAGENT_COMPUTER_USE`.

### `--no-frontend`

เรียกใช้ API เท่านั้น โดยไม่ใช้แม่แบบ HTML หรือไฟล์ frontend แบบคงที่.

### `--embedded`

ปิดการใช้งานที่เก็บเซสชันและซ่อนเครื่องมือจัดการเครื่องมือ (`tool_catalog`, `tool_load`, `unload_tool`).

## ตัวเลือกเซิร์ฟเวอร์ A2A (`uaga`)

### `--host <address>`

ที่อยู่สำหรับผูกเซิร์ฟเวอร์ A2A HTTP (ค่าเริ่มต้น: `0.0.0.0`, สามารถกำหนดใหม่ได้ผ่าน `UAGENT_A2A_HOST`).

### `--port <number>`

หมายเลขพอร์ตสำหรับเซิร์ฟเวอร์ A2A HTTP (ค่าเริ่มต้น: `8765`, สามารถกำหนดใหม่ได้ผ่าน `UAGENT_A2A_PORT`).

### `--reload`

เปิดใช้งานการรีโหลดแบบร้อนเมื่อมีการเปลี่ยนแปลงโค้ด (ค่าเริ่มต้น: ปิด, สามารถเปลี่ยนได้ผ่าน `UAGENT_A2A_RELOAD`).

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

เลือกประเภทเครื่องมือโดยใช้บิตมาสก์เดียวกันที่อธิบายไว้ข้างต้น เมื่อกำหนดไว้ หน้าจอถามประเภทเครื่องมือแบบโต้ตอบจะถูกข้ามไป

### `--use-tool` / `--no-use-tool`

เปิดหรือปิดการส่งคำจำกัดความเครื่องมือไปยัง LLM แทนที่ `UAGENT_USE_TOOL`.

### `--computer-use` / `--no-computer-use`

เปิดหรือปิดการใช้งาน Computer Use. แทนที่ `UAGENT_COMPUTER_USE`.

### `--embedded`

ปิดการใช้งานที่เก็บเซสชันและซ่อนเครื่องมือจัดการเครื่องมือ (`tool_catalog`, `tool_load`, `unload_tool`).

## ตัวแปรสภาพแวดล้อมที่เกี่ยวข้อง

| ตัวแปร | คำอธิบาย |
|---|---|
| `UAGENT_PROVIDER` | ชื่อผู้ให้บริการ LLM (จำเป็นเมื่อเริ่มต้นระบบ) |
| `UAGENT_*_API_KEY` | คีย์ API สำหรับผู้ให้บริการที่เลือก |
| `UAGENT_WORKDIR` | ไดเรกทอรีทำงานเริ่มต้น |
| `UAGENT_WEB_HOST` | ที่อยู่ผูกมัดของเซิร์ฟเวอร์เว็บ (ค่าเริ่มต้น: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A ที่อยู่การผูกมัดของเซิร์ฟเวอร์ (ค่าเริ่มต้น: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | พอร์ตเซิร์ฟเวอร์ A2A (ค่าเริ่มต้น: `8765`) |
| `UAGENT_A2A_RELOAD` | เปิดใช้งานการรีโหลดแบบร้อน (hot reload) ของ A2A เป็นค่าเริ่มต้น |
| `UAGENT_USE_TOOL` | ปิดใช้งานเครื่องมือเมื่อตั้งค่าเป็น `0`, `false`, `no` หรือ `off` |
| `UAGENT_COMPUTER_USE` | เปิดหรือปิดใช้งาน Computer Use เป็นค่าเริ่มต้น |
| `UAGENT_SESSION_STORE` | เปิดหรือปิดการเก็บเซสชัน; โหมดฝังตัวบังคับให้ใช้ `0` |
| `UAGENT_PLUGIN_DIRS` | ไดเรกทอรีค้นหาปลั๊กอินเพิ่มเติม |
| `UAGENT_AUTO_SENTINEL` | เปิดใช้งานโหมดเซ็นทิเนลอัตโนมัติแบบ single-LLM เมื่อตั้งค่าเป็น `1` |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | จำนวนการเรียกเครื่องมือใหม่ติดต่อกันสูงสุด (ค่าเริ่มต้น: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | จำนวนรอบ LLM/เครื่องมือสูงสุดต่อการดำเนินการของผู้ใช้ (ค่าเริ่มต้น: `200`) |
| `UAGENT_SHRINK_CNT` | ค่าเกณฑ์การบีบอัดอัตโนมัติในข้อความ (เลือกได้) (`0`/ไม่ตั้งค่า = ปิดใช้งาน) |
| `UAGENT_SHRINK_KEEP_LAST` | จำนวนข้อความที่จะเก็บไว้หลังการบีบอัด (ค่าเริ่มต้น: `20`) |
| `UAGENT_LANG` | ภาษาของอินเทอร์เฟซ (`ja`, `en`, เป็นต้น) |

สำหรับรายชื่อตัวแปรสภาพแวดล้อมทั้งหมด ดู [ENVIRONMENT.md](ENVIRONMENT.md).

## ตัวอย่าง

### การเริ่มต้นแบบขั้นต่ำด้วย OpenAI

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### Ollama แบบท้องถิ่นที่ใช้เพียงเครื่องมือพื้นฐาน

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### เว็บเซิร์ฟเวอร์บนทุกอินเทอร์เฟซ

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

หรือ

```
uagw --host 0.0.0.0
```

### A2A เซิร์ฟเวอร์บน localhost ด้วยพอร์ตที่กำหนดเอง

```
uaga --host 127.0.0.1 --port 8080
```

### ปิดใช้งานเครื่องมือสำหรับโมเดลขนาดเล็ก

```
uag --no-use-tool --tool-genre-mask 1
```

### การประมวลผลไฟล์แบบไม่โต้ตอบ

```
uag --non-interactive README.md
```
