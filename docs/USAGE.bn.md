# ব্যবহার (কমান্ড-লাইন বিকল্প)

এই ডকুমেন্টে uag এন্ট্রি পয়েন্টগুলির জন্য উপলব্ধ কমান্ড-লাইন বিকল্পগুলি বর্ণনা করা হয়েছে।

______________________________________________________________________

## এন্ট্রি পয়েন্টসমূহ

| কমান্ড | পাইথন মডিউল | ইন্টারফেস |
|---|---|---|
| `uag` | `python -m uagent` | CLI (stdin লুপ) |
| `uagg` | `python -m uagent.gui` | GUI (tkinter) |
| `uagw` | `python -m uagent.web` | ওয়েব সার্ভার (FastAPI) |
| `uaga` | `python -m uagent.a2a.server` | A2A HTTP সার্ভার |

## CLI স্টার্টআপ অপশন (`uag`)

### `--workdir` / `-C <path>`

ওয়ার্কিং ডিরেক্টরি। যদি সেট না করা হয়, তাহলে `UAGENT_WORKDIR` এনভায়রনমেন্ট ভেরিয়েবলে ফিরে যায়, তারপর বর্তমান ডিরেক্টরিতে।
যদি ডিরেক্টরিটি বিদ্যমান না থাকে, তবে তা তৈরি করা হয়।

### `--tool-genre-mask <int>`

টুল জেনারের বিটমাস্ক। প্রদান করলে, ইন্টারেক্টিভ ঘরানা নির্বাচন প্রম্পট এড়িয়ে যাওয়া হয়।

| বিট | ঘরানা | বর্ণনা |
|-----|-------|-------------|
| 1 | basic | মৌলিক ফাইল/চ্যাট টুলস |
| 2 | comm | যোগাযোগের সরঞ্জাম (Bluesky, Teams) |
| 4 | office | অফিস স্যুট সরঞ্জাম (Excel, PDF, PPTX) |
| 8 | devel | ডেভেলপমেন্ট সরঞ্জাম (git, lint, compile) |
| 16 | iot | IoT ডিভাইস টুলস (SwitchBot, ECHONET, Matter, UPnP) |
| 32 | exec | কমান্ড এক্সিকিউশন টুলস |
| 64 | external | এক্সটার্নাল প্লাগইন টুলস |
| 128 | media | ইমেজ/অডিও জেনারেট এবং বিশ্লেষণ |
| 256 | file | ফাইল-ম্যানেজমেন্ট টুলস |
| 512 | index | সোর্স/ইনডেক্স নেভিগেশন টুলস |
| 1024 | dev | ডেভেলপার এবং রিপোজিটরি টুলস |
| 2048 | web | ওয়েব এবং ব্রাউজার টুলস |
| 4096 | utility | ইউটিলিটি এবং সাপোর্ট টুলস |
| 8191 | all | সব টুলস |

উদাহরণ:

```
uag --tool-genre-mask 1 # শুধুমাত্র মৌলিক
uag --tool-genre-mask 9 # মৌলিক + ডেভেল (1 + 8)
uag --tool-genre-mask 8191    # সব টুল
```

### `--use-tool` / `--no-use-tool`

LLM-এ টুল সংজ্ঞা পাঠানো সক্ষম বা অক্ষম করুন। `UAGENT_USE_TOOL` পরিবেশ ভেরিয়েবলকে ওভাররাইড করে।

- `--use-tool` টুল পাঠানো চালু করে।
- `--no-use-tool` টুল পাঠানো বন্ধ করে।

অক্ষম থাকলে, LLM কোনো টুল সংজ্ঞা গ্রহণ করে না এবং কোনো টুল কল করতে পারে না।

### `--computer-use` / `--no-computer-use`

কম্পিউটার ব্যবহার সক্ষম বা অক্ষম করুন। `UAGENT_COMPUTER_USE` পরিবেশ ভেরিয়েবলকে ওভাররাইড করে।

### `--inject-message` / `-M <message>`

শুরুতে LLM-এ একটি বার্তা ইনজেক্ট করে এবং সম্পন্ন হওয়ার পর প্রস্থান করে। এটি `--non-interactive` নির্দেশ করে।

### `--embedded`

সীমাবদ্ধ বা পুনরুত্পাদন-সংবেদনশীল মোতায়েনের জন্য এমবেডেড মোড।

- সেশন স্টোর নিষ্ক্রিয় করে।
- স্পষ্টভাবে সক্ষম না করা থাকলে টুল-ম্যানেজমেন্ট টুল (`tool_catalog`, `tool_load`, `unload_tool`) লুকিয়ে রাখে।
- `--tool-genre-mask` উপেক্ষা করে; স্পষ্টভাবে টুল লোড করার জন্য `--enable-tool` ব্যবহার করুন।

### `--enable-tool <name>`

স্টার্টআপে একটি টুল স্পষ্টভাবে লোড করুন। এই অপশনটি একাধিকবার ব্যবহার করা যেতে পারে, এবং কমা-বিচ্ছিন্ন নামও গ্রহণযোগ্য।

```
uag --embedded --enable-tool handle_mcp_v2 --enable-tool human_ask
uag --embedded --enable-tool handle_mcp_v2,human_ask
```

নির্দিষ্ট ক্রমটি সংরক্ষিত থাকে এবং LLM-এ প্রদর্শিত টুল অর্ডারে প্রতিফলিত হয়। স্পষ্টভাবে সক্ষমকৃত টুলগুলো স্বয়ংক্রিয় আনলোডিং থেকে সুরক্ষিত থাকে।

### `--plugin-dir <path>`

নির্দিষ্ট ডিরেক্টরি থেকে প্লাগইন লোড করুন। এই অপশনটি পুনরাবৃত্তি করা যেতে পারে।

## শুধুমাত্র CLI-র জন্য অপশনসমূহ

### `--inject-message-auto <goal-options>`

নন-ইন্টার‌্যাক্টিভ ইনজেক্টেড গোল থেকে অটো-পাইলট শুরু করুন। মানটি `:auto`-এর মতো একই অপশন ব্যবহার করে; যখন এতে অপশন থাকে, তখন সম্পূর্ণ মানটি উদ্ধৃত করুন।

```
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --max-rounds 10"
uag --embedded --enable-tool handle_mcp_v2 --inject-message-auto "Sort the items --infinite"
```

সাধারণ মোড পর্যালোচকের বিচার পথ ব্যবহার করে। একক-LLM সেন্টিনেল মোডে অংশ নিতে `UAGENT_AUTO_SENTINEL=1` সেট করুন। সেই মোডে, টার্গেট LLM প্রতিটি প্রতিক্রিয়া ঠিক একটি দিয়ে শেষ করতে হবে:

- `<AUTO_CONTINUE>` — আরেকটি রাউন্ড চালান
- `<AUTO_COMPLETE>` — সফলভাবে শেষ করুন

অভাবিত বা অবৈধ মার্কারগুলো অটো-পাইলটকে নিরাপদে থামিয়ে দেয়। এটি টার্গেট LLM চালিয়ে যায়; এটি শুধুমাত্র অতিরিক্ত রিভিউয়ার LLM কল এড়িয়ে চলে।

### `--non-interactive`

নন-ইন্টার‌্যাক্টিভ মোড। stdin লুপ শুরু করে না। যদি কোনো ফাইল পথ পজিশনাল আর্গুমেন্ট হিসেবে দেওয়া হয়, তা প্রক্রিয়া করা হয় এবং প্রোগ্রামটি অবিলম্বে বন্ধ হয়ে যায়।

```
uag --non-interactive README.md
uag --non-interactive --workdir /tmp/project
```

## ওয়েব সার্ভার অপশন (`uagw`)

### `--host <address>`

ওয়েব সার্ভারের বাইন্ড ঠিকানা (ডিফল্ট: `127.0.0.1`, `UAGENT_WEB_HOST` দ্বারা ওভাররাইডযোগ্য)।

ডিফল্টভাবে, ওয়েব সার্ভার শুধুমাত্র localhost (`127.0.0.1`) এ শোনা করে। নেটওয়ার্কের অন্যান্য মেশিন থেকে এটি অ্যাক্সেসযোগ্য করতে `--host 0.0.0.0` ব্যবহার করুন।

```
uagw --host 0.0.0.0
uagw --host 192.168.1.10
```

### `--tool-genre-mask <int>`

উপরের বর্ণিত একই বিটমাস্ক ব্যবহার করে টুল ঘরানা নির্বাচন করুন। নির্দিষ্ট করলে, ইন্টারেক্টিভ জেনারের প্রম্পট এড়িয়ে যায়।

### `--use-tool` / `--no-use-tool`

টুল সংজ্ঞা LLM-এ পাঠানোর সুবিধা চালু বা বন্ধ করুন। `UAGENT_USE_TOOL` ওভাররাইড করে।

### `--computer-use` / `--no-computer-use`

কম্পিউটার ব্যবহার সক্ষম বা অক্ষম করুন। `UAGENT_COMPUTER_USE` ওভাররাইড করে।

### `--no-frontend`

শুধুমাত্র API চালান, HTML টেমপ্লেট বা স্ট্যাটিক ফ্রন্টএন্ড ফাইল ছাড়া।

### `--embedded`

সেশন স্টোর নিষ্ক্রিয় করে এবং টুল-ম্যানেজমেন্ট টুল (`tool_catalog`, `tool_load`, `unload_tool`) লুকিয়ে রাখে।

## A2A সার্ভার অপশন (`uaga`)

### `--host <address>`

A2A HTTP সার্ভারের বাইন্ড ঠিকানা (ডিফল্ট: `0.0.0.0`, `UAGENT_A2A_HOST` দ্বারা ওভাররাইডযোগ্য)।

### `--port <সংখ্যা>`

A2A HTTP সার্ভারের পোর্ট নম্বর (ডিফল্ট: `8765`, `UAGENT_A2A_PORT` দ্বারা ওভাররাইডযোগ্য)।

### `--reload`

কোড পরিবর্তনের সময় হট রিলোড সক্ষম করে (ডিফল্ট: বন্ধ, `UAGENT_A2A_RELOAD` দ্বারা ওভাররাইডযোগ্য)।

```
uaga --host 127.0.0.1 --port 8080 --reload
```

### `--tool-genre-mask <int>`

উপরের বিটমাস্ক ব্যবহার করে টুল ঘরানা নির্বাচন করুন। নির্দিষ্ট করলে, ইন্টারেক্টিভ ঘরানা প্রম্পট এড়িয়ে যাওয়া হয়।

### `--use-tool` / `--no-use-tool`

LLM-এ টুল সংজ্ঞা পাঠানোর সুবিধা চালু বা বন্ধ করুন। `UAGENT_USE_TOOL` ওভাররাইড করে।

### `--computer-use` / `--no-computer-use`

কম্পিউটার ব্যবহার সক্ষম বা অক্ষম করুন। `UAGENT_COMPUTER_USE` ওভাররাইড করে।

### `--embedded`

সেশন স্টোর নিষ্ক্রিয় করে এবং টুল-ম্যানেজমেন্ট টুল (`tool_catalog`, `tool_load`, `unload_tool`) লুকিয়ে রাখে।

## সম্পর্কিত পরিবেশ ভেরিয়েবল

| ভেরিয়েবল | বর্ণনা |
|---|---|
| `UAGENT_PROVIDER` | LLM প্রদানকারীর নাম (শুরুতে প্রয়োজনীয়) |
| `UAGENT_*_API_KEY` | API নির্বাচিত প্রদানকারীর জন্য কী |
| `UAGENT_WORKDIR` | ডিফল্ট কর্ম ডিরেক্টরি |
| `UAGENT_WEB_HOST` | ওয়েব সার্ভার বাইন্ড ঠিকানা (ডিফল্ট: `127.0.0.1`) |
| `UAGENT_A2A_HOST` | A2A সার্ভার বাইন্ড ঠিকানা (ডিফল্ট: `0.0.0.0`) |
| `UAGENT_A2A_PORT` | A2A সার্ভার পোর্ট (ডিফল্ট: `8765`) |
| `UAGENT_A2A_RELOAD` | A2A হট রিলোড ডিফল্টরূপে সক্ষম করুন |
| `UAGENT_USE_TOOL` | যখন `0`, `false`, `no`, বা `off` এ সেট করা হয় তখন টুলস নিষ্ক্রিয় করে |
| `UAGENT_COMPUTER_USE` | ডিফল্টরূপে কম্পিউটার ব্যবহার সক্ষম বা অক্ষম করুন |
| `UAGENT_SESSION_STORE` | সেশন স্টোর সক্ষম বা অক্ষম করুন; এমবেডেড মোড `0` বাধ্য করে |
| `UAGENT_PLUGIN_DIRS` | অতিরিক্ত প্লাগইন অনুসন্ধান ডিরেক্টরি |
| `UAGENT_AUTO_SENTINEL` | `1` এ সেট করলে একক LLM অটো-পাইলট সেন্টিনেল মোডে অপ্ট-ইন করুন |
| `UAGENT_CONSECUTIVE_TOOL_CALL_LIMIT` | সর্বোচ্চ ধারাবাহিক নতুন টুল কল (ডিফল্ট: `100`) |
| `UAGENT_MAX_TOOL_ROUNDS` | প্রতি ব্যবহারকারী অপারেশনের সর্বোচ্চ LLM/টুল রাউন্ড (ডিফল্ট: `200`) |
| `UAGENT_SHRINK_CNT` | বার্তায় ঐচ্ছিক স্বয়ং-সংকোচন থ্রেশহোল্ড (`0`/অনির্ধারিত = অক্ষম) |
| `UAGENT_SHRINK_KEEP_LAST` | সংকোচনের পর সংরক্ষণ করার বার্তা (ডিফল্ট: `20`) |
| `UAGENT_LANG` | ইন্টারফেস ভাষা (`ja`, `en`, ইত্যাদি) |

পরিবেশ ভেরিয়েবলগুলির সম্পূর্ণ তালিকা দেখতে [ENVIRONMENT.md](ENVIRONMENT.md) দেখুন।

## উদাহরণ

### OpenAI দিয়ে ন্যূনতম শুরু

```
set UAGENT_PROVIDER=openai
set UAGENT_OPENAI_API_KEY=sk-...
uag
```

### শুধুমাত্র মৌলিক টুলস সহ লোকাল ওল্লামা

```
set UAGENT_PROVIDER=ollama
set UAGENT_OLLAMA_MODEL=qwen2.5:7b
uag --tool-genre-mask 1
```

### সব ইন্টারফেসে ওয়েব সার্ভার

```
set UAGENT_WEB_HOST=0.0.0.0
uagw
```

অথবা

```
uagw --host 0.0.0.0
```

### A2A সার্ভার লোকালহোস্টে কাস্টম পোর্টে

```
uaga --host 127.0.0.1 --port 8080
```

### ছোট মডেলের জন্য টুল নিষ্ক্রিয়করণ

```
uag --no-use-tool --tool-genre-mask 1
```

### অ-ইন্টার‌্যাক্টিভ ফাইল প্রসেসিং

```
uag --non-interactive README.md
```
